# 插件系统（实验性）

插件通过 WebAssembly 计算和声明式配置扩展 FFmpeg++。先在 **设置 → 实验性功能 → 插件系统** 打开开关；默认关闭。打开后，桌面端从左侧栏进入，移动端从底部导航进入。

插件页可以导入插件包、查看详情与权限、启用/禁用/卸载、回滚可用的旧版本，并在新增入口导出完整开发 SDK。插件可展示作者名称和自定义图标。安装后的插件保持禁用；启用前须确认来源与风险提示，预览版还需确认稳定性提示。文件与网络权限默认不授予，由使用者逐项选择。

含节点的插件提供 **节点配置** 按钮，可逐项启用或禁用节点，更改会立即显示并保存。禁用节点会从可添加的节点列表中移除；已有图中的节点及参数保留，但在重新启用前无法执行。插件详情和卡片内的节点列表也提供相同开关。

设置开关与运行时状态分别显示。若提示“插件设置已开启，运行时尚未就绪”，请检查后端是否已启动并支持插件运行时；无需反复切换已开启的设置。

## 能力边界

节点插件声明名称、功能、输入/输出媒体类型、端口及参数，宿主负责构建原生 Flutter 表单和节点视图。WASM 不能直接创建 Widget 或修改 Flutter Theme。v1 媒体节点固定一入一出；插件可返回既有安全操作，或在 backend 实际发现支持时通过 `ffmpeg.execute` 提交受限输出选项。仅该操作允许跨视频、音频、图像类型，输入/输出路径仍由宿主任务管理。

主题插件是受白名单约束的配置预设，能够选择已有液态玻璃样式；新增一种宿主尚未实现的渲染器仍需修改宿主。AI 配置插件可以只含供应商和模型目录，不需要 WASM，不包含密钥。应用主题、导入 AI 配置都需要显式预览和确认。

关闭实验开关后不会执行插件；已有图中的插件节点继续保留身份、参数和显示快照，待重新安装/启用兼容插件后恢复使用。图中的声明快照只用于展示，不作为执行授权依据。
