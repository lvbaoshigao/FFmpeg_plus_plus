# 插件系统（实验性）

插件通过 WebAssembly 计算和声明式配置扩展 FFmpeg++。先在 **设置 → 实验性功能 → 插件系统** 打开开关；默认关闭。打开后，桌面端从左侧栏进入，移动端从底部导航进入。

插件页可以导入插件包、查看信息与权限、启用/禁用/卸载、回滚可用的旧版本，并在新增入口导出开发 SDK。安装后的插件保持禁用；预览版必须先确认稳定性提示。

## 能力边界

节点插件声明名称、功能、媒体类型、端口及参数，宿主负责构建原生 Flutter 表单和节点视图。WASM 不能直接创建 Widget 或修改 Flutter Theme。v1 媒体节点是一入一出，返回受支持的操作描述，由宿主接入现有任务、逻辑控制和后端执行流程。

主题插件是受白名单约束的配置预设，能够选择已有液态玻璃样式；新增一种宿主尚未实现的渲染器仍需修改宿主。AI 配置插件可以只含供应商和模型目录，不需要 WASM，不包含密钥。应用主题、导入 AI 配置都需要显式预览和确认。

关闭实验开关后不会执行插件；已有图中的插件节点继续保留身份、参数和显示快照，待重新安装/启用兼容插件后恢复使用。图中的声明快照只用于展示，不作为执行授权依据。
