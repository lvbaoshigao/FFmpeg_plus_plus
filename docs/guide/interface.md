# 1.5 界面导览

先认入口，不用一下子记住所有按钮。

## 桌面端的几个主要页面

| 页面 | 主要做什么 | 入门建议 |
| --- | --- | --- |
| 项目 | 添加、探测和选择媒体，进入处理配置 | 从这里导入第一份素材 |
| 处理队列 | 看任务、进度、输出与失败信息 | 配置完成后到这里确认结果 |
| 配置库 | 管理可复用的节点配置与快捷配置 | 流程稳定后存一个模板 |
| 设置 | 调整外观、处理参数、AI 和高级选项 | 先关心输出与环境即可 |
| 日志 | 看分类信息，复制排障内容 | 出错时比反复点击更有用 |

## 点进媒体之后，会看到什么？

进入哪种处理界面，与编辑模式和操作入口有关。节点模式会打开画布，快捷模式会打开顺序配置界面。需要切换时看[编辑器设置](../settings/editor.md)。

节点编辑器里，先认这四块：

- **工具栏**：保存、撤销重做、整理和视图相关操作。
- **画布**：摆节点、拖连线。
- **元素面板**：找节点；桌面端单击可以先看属性，双击或拖放才真正创建。
- **属性面板**：改选中节点的参数。

完整操作见[第二章](../nodes/index.md)。有些面板可以在桌面端拆成独立窗口；这会增加独立窗口的资源开销，不需要时直接关闭子窗口让它恢复到主界面。

## Android 的入口为什么不完全一样？

手机主要通过底部导航切换项目、队列、配置库和设置，日志入口可在设置中找到。编辑器也会换成更适合触屏的面板操作。

“在桌面双击元素添加”和“在手机点击元素添加”并不冲突，它们是不同输入方式。手册会在必要处分别说明。
