# 1.5 界面导览

本节说明主要页面及节点编辑器各区域的职责，并列出桌面端与 Android 的导航差异。

## 桌面端主要页面

| 页面 | 主要职责 | 使用建议 |
| --- | --- | --- |
| 项目 | 添加、探测和选择媒体，进入处理配置 | 作为媒体导入入口 |
| 处理队列 | 查看任务、进度、输出与失败信息 | 在此检查任务状态与结果 |
| 配置库 | 管理可复用的节点配置与快捷配置 | 将已验证的流程保存为模板 |
| 设置 | 调整外观、处理参数、AI 和高级选项 | 首次使用时优先检查输出与环境 |
| 日志 | 查看分类信息，复制排障内容 | 用于定位异常并保留诊断信息 |

## 媒体编辑界面

媒体文件打开的编辑界面取决于编辑模式与操作入口。节点模式打开画布，快捷模式打开串行配置界面。切换方法见[编辑器设置](../settings/editor.md)。

节点编辑器包含以下主要区域：

- **工具栏**：保存、撤销重做、整理和视图相关操作。
- **画布**：放置节点并建立连线。
- **元素面板**：查找节点；桌面端单击用于查看属性，双击或拖放用于创建节点。
- **属性面板**：编辑选中节点的参数。

完整操作见[第二章](../nodes/index.md)。桌面端部分面板支持拆分为独立窗口。独立窗口会增加资源开销；关闭子窗口后，面板恢复至主界面。

## Android 导航与输入方式

Android 主要通过底部导航切换项目、队列、配置库和设置，日志入口位于设置中。编辑器使用适合触屏的面板操作方式。

创建元素的操作随输入方式而变化：桌面端使用双击，Android 使用点击。相关章节分别说明各平台的操作。

::: tip 操作入口的显示条件
若未显示预期按钮，应核对平台、当前选中对象，以及普通文件或容器的编辑上下文。部分功能仅在对应条件下显示。
:::

操作示例见[使用短视频完成第一个任务](./first-task.md)。
