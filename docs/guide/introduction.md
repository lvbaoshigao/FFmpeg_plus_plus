# 1.1 软件介绍与 1.2 软件功能

你可以把 FFmpeg++ 理解为 FFmpeg 的一张“操作台”：导入媒体，把需要的处理步骤连起来，再交给队列执行。底下真正处理视频、音频和图片的，仍然是 FFmpeg / ffprobe。

## 1.1 这款软件适合谁？

如果你经常做转码、剪一段素材、烧录字幕、调音量，或者把同一套处理步骤用到很多文件上，就可以从这里开始。它把常用参数放进图形界面。

界面由 Flutter 编写，原生后端使用 C++17，通过 FFI 与界面通信。知道这一点就够了：**界面能打开，不代表后端和 FFmpeg 一定都已经就绪**；首次启动要留意环境检查。

## 1.2 先选一种顺手的用法

| 用法 | 什么时候选它 | 下一步 |
| --- | --- | --- |
| 节点编辑器 | 想看清步骤顺序，或需要逻辑、容器等进阶流程 | [认识编辑器](../nodes/index.md) |
| 快捷配置 | 想给单个文件快速排一条串行处理链 | [快捷配置](../features/quick-config.md) |

先别纠结“哪种最专业”。你只想压缩一个视频，用快捷配置就很合适；当步骤变多，再换到节点编辑器。

## 能做些什么？

- **视频**：音视频处理、字幕、时间截取、帧提取、变速、帧率、去隔行、倒放和淡入淡出。
- **音频**：音质、音量、压缩、响度、降噪、静音裁剪、均衡器，以及生成频谱图、波形图。
- **图片与通用处理**：格式、尺寸、裁剪、旋转、颜色、水印、锐化、降噪和压缩等；通用节点要先选择媒体类型。
- **组合与复用**：容器处理、媒体拼接、图片合成视频、配置库和 `.fppx` 文件交换。
- **辅助工具**：任务队列、日志、AI 助手、MCP、外观与快捷键设置。

完整的可选节点以[节点参考](../nodes/video.md)为准。旧工程里的兼容节点，不一定还会出现在新建节点列表里。

::: tip 一条重要边界
有这个节点，不等于任意素材和任意参数都能处理。编码器能否使用，还取决于 FFmpeg 的编译能力、设备和驱动；流程是否能运行，则要通过图校验并实际完成任务。
:::
