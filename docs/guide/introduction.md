# 1.1 软件介绍与 1.2 软件功能

FFmpeg++ 是基于 FFmpeg 的图形化媒体处理应用。用户导入媒体并配置处理流程后，通过任务队列执行。应用调用 FFmpeg 处理视频、音频和图片，并使用 ffprobe 读取媒体信息。

## 1.1 适用场景与架构

应用适用于转码、片段截取、字幕烧录、音量调整及批量复用处理流程等场景，通过图形界面配置常用处理参数。

界面使用 Flutter，原生后端使用 C++17，二者通过 FFI 通信。**界面正常启动不表示后端与 FFmpeg 已就绪**；首次启动时，应检查应用内的环境检测结果。

## 1.2 处理模式

| 模式 | 适用场景 | 参考章节 |
| --- | --- | --- |
| 节点编辑器 | 查看处理顺序，或配置逻辑控制、容器等复杂流程 | [认识编辑器](../nodes/index.md) |
| 快捷配置 | 为单个文件配置串行处理链 | [快捷配置](../features/quick-config.md) |

快捷配置适合视频压缩等串行任务；需要更复杂的处理关系时，可使用节点编辑器。

## 主要功能

- **视频**：音视频处理、字幕、时间截取、帧提取、变速、帧率、去隔行、倒放和淡入淡出。
- **音频**：音质、音量、压缩、响度、降噪、静音裁剪、均衡器，以及生成频谱图、波形图。
- **图片与通用处理**：格式、尺寸、裁剪、旋转、颜色、水印、锐化、降噪和压缩等；通用节点要先选择媒体类型。
- **组合与复用**：容器处理、媒体拼接、图片合成视频、配置库和 `.fppx` 文件交换。
- **辅助工具**：任务队列、日志、AI 助手、MCP、外观与快捷键设置。

可选节点及其参数见[节点参考](../nodes/video.md)。旧工程中的兼容节点可能不再出现在新建节点列表中。

::: tip 功能适用条件
节点可用不表示其支持任意素材或参数组合。编码器的可用性取决于 FFmpeg 的编译选项、设备与驱动；流程须通过图校验，并以实际任务结果验证。
:::
