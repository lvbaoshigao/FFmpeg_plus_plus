# 6.3 术语：界面里这些词指什么

遇到不熟悉的词，可以先查这里，再回相关章节操作。这些解释按应用中的用法组织，不要求你先学完整套音视频理论。

## 项目、流程与任务

| 术语 | 在 FFmpeg++ 中的意思 | 容易混淆的点 |
| --- | --- | --- |
| 项目/媒体列表 | 当前加入应用、准备处理的媒体 | 添加成功不等于解析成功 |
| 探测/解析 | 读取媒体编码、时长、尺寸、轨道等信息 | 不会因此生成转码成品 |
| 节点 | 一个处理、输入输出或逻辑步骤 | 节点外观不是实际视频效果预览 |
| 管线/流程/节点图 | 节点及连线形成的处理关系 | 不只是画布上从左到右的位置 |
| 串行链 | 一步接一步的有序处理 | 快捷配置不支持任意分支 |
| 容器 | 应用内一组文件及共用流程 | 不是 MP4/MKV 那种媒体封装容器 |
| 独立文件流程 | 绑定某一个文件的配置 | 容器整体运行仍用容器流程 |
| 配置库 | 可重复应用的模板集合 | 不是媒体素材库 |
| FPPX | 配置交换文件 | 不自动包含全部媒体与外部依赖 |
| 草稿自动保存 | 编辑器定期留存恢复信息 | 不是完整项目备份或编码断点续传 |
| 入队 | 创建等待执行的任务 | 不等于立即开始 |
| 终态 | 完成、失败、取消这些结束状态 | “清除已完成”会清理这些终态记录 |

## 媒体处理

| 术语 | 简单理解 |
| --- | --- |
| FFmpeg / FFprobe | 前者负责实际媒体处理，后者用于读取媒体信息；具体流程可能还会调用其他探测能力 |
| 编码器 | 将媒体编码成特定压缩格式的实现，例如 H.264 的 x264、NVENC、MediaCodec |
| 编码格式与封装格式 | H.264/HEVC/AAC 属于编码；MP4/MKV 等是装这些流的封装。改扩展名不等于完成转码 |
| 复制流（copy） | 尽量不重新编码地复制压缩数据；需要滤镜或不兼容封装时不能一概使用 |
| 硬编 | 用设备专用编码能力处理，仍依赖编译支持、驱动和参数 |
| NVENC / AMF / QSV | 桌面 NVIDIA / AMD / Intel 对应硬编接口名称 |
| MediaCodec | Android 媒体编解码接口，本应用当前提供 H.264/HEVC 编码选项 |
| 分辨率 | 图像宽高的像素数；不等同于码率或文件大小 |
| 帧率（fps） | 视频每秒帧数；与应用界面高刷新率不是同一设置 |
| 码率 | 每秒数据量；与输出体积有关，但不等于质量的唯一指标 |
| 中间文件 | 多步骤之间暂存的产物，会占用额外磁盘 |
| 多帧提取 | 一次输出多张帧图，可能以目录形式传递，不能直接当一张图片处理 |

## AI 与平台

| 术语 | 本应用中的用法 |
| --- | --- |
| 提供商 | 一份模型服务连接与管理配置 |
| API Key | 模型服务凭据，不是 MCP 访问令牌 |
| 模型能力标记 | 告诉客户端怎样构造请求，不能替服务端增加能力 |
| 上下文窗口 | 一轮请求能携带的信息预算，包含提示、画布、历史等 |
| token | 模型计量文本/请求预算的单位，不等同于汉字数 |
| 询问模式 | 图应用等操作先确认；部分操作可能被跳过询问列表放行 |
| MCP | 外部兼容客户端访问本机工具/资源的协议入口，与内置聊天分开 |
| 回环地址 | 例如 127.0.0.1，只指当前设备本机 |
| Bearer token | 非回环 MCP 连接可用的认证方式之一，需随请求发送令牌 |
| SAF / content URI | Android 文档访问机制返回的引用，不一定是 FFmpeg 能直接打开的文件路径 |
| 预加载/预热 | 启动时提前构建页面、枚举字体、解码壁纸等准备工作 |
| 流体云 / 超级岛 | 厂商特色进度通知，受 ROM、协议、接入及权限限制 |

想把这些词用起来，可以从[快捷配置](../features/quick-config.md)、[配置库](../features/library.md)、[AI 助手](../features/ai.md)或[平台差异](../settings/platforms.md)继续。
