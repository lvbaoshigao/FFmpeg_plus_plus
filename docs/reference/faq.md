# 6.1 常见问题与故障定位

排查问题时，应先确定异常发生在媒体导入、流程配置、任务入队、执行或结果访问阶段，再检查对应条件。无需将重置全部设置作为首要步骤。

~~~text
无法添加文件 → 检查来源、扩展名与本地可读路径
文件已添加但解析失败 → 检查 FFprobe 与媒体内容
配置无法保存或应用 → 检查类型、连线与节点参数
任务已入队但未执行 → 检查队列启动状态、任务状态与并发设置
任务执行失败 → 检查任务错误、实际命令与日志
无法访问输出结果 → 检查任务实际输出路径，并使用打开文件或定位操作
~~~

## 导入与配置

### 文件已添加到列表，为什么仍无法处理？

文件添加与媒体解析是两个阶段。应等待解析完成；解析失败时，检查 FFprobe 错误。增加“解析线程数”仅调整导入探测的并行程度，无法修复损坏媒体或不可读路径。[媒体导入](../features/project.md)

### 为什么未导入文件夹的子目录？

“从文件夹创建容器”仅扫描所选目录中的普通媒体文件，并按扩展名筛选，不递归扫描子目录。需要导入子目录内容时，可分别创建容器或手动选择文件。[容器操作](../features/project.md)

### 为什么快捷配置中没有显示某个节点？

候选节点由当前处理链末端的媒体类型决定。快捷配置不支持逻辑门、分支或多文件合并。应先检查上游输出类型；需要复杂结构时，使用节点编辑器。[快捷配置](../features/quick-config.md)

### 为什么选择快速模式后仍需使用节点编辑器？

已有节点图包含分支、逻辑、孤立节点或其他无法串行化的结构时，应用不会自动删减为串行链。应继续在节点编辑器中编辑，或为其他文件建立串行流程。

### 应用已保存配置时，为什么未显示某个模板？

列表仅显示兼容且通过校验的配置。应检查媒体类型、源节点声明与参数。应用到文件时使用流程副本，不会直接修改模板。[配置库](../features/library.md)

### 为什么修改容器内文件的独立配置后，容器批处理未采用该配置？

“应用到文件”仅修改文件的独立流程，容器任务仍使用容器共用流程。需要调整容器批处理时，应编辑容器流程；仅处理该文件时，应使用文件的独立处理入口。

## 执行与结果

### 任务入队后是否立即执行？

入队仅创建等待任务。应在队列中点击“开始处理”，或单独启动等待任务。暂停任务仍占用并发槽位，须继续或停止后才能改变其占用状态。[队列](../features/queue.md)

### 为什么暂停操作不可用或执行失败？

任务可能处于步骤切换阶段，暂时没有可冻结的进程；Windows 本地进程执行路径也存在冻结信号限制。暂停失败时，应用不会将任务状态标记为暂停。重启后，原暂停任务会重置为等待状态，不支持断点续传。

### 为什么“清除已完成”同时移除了失败记录？

该操作移除所有处于终态的任务记录，包括完成、失败与取消。清理前应保留所需排障信息。移除记录不会删除输出文件。[日志](../features/logs.md)

### 为什么提高并发数后，处理速度反而下降？

多个任务可能争用 CPU、GPU、内存或磁盘资源。可降低同时运行的任务数，并比较处理时间。任务并发数、导入解析线程数与编码器内部线程数属于不同设置。[处理设置](../settings/processing.md)

### Android 是否支持硬件编码？

应用提供 H.264/HEVC MediaCodec 编码选项。实际可用性取决于设备、FFmpeg 构建及参数组合；发生错误时，应结合具体错误信息检查硬件编码配置。[平台差异](../settings/platforms.md)

## AI、通知与空间

### 为什么配置 Responses API 后仍无法发送请求？

当前统一 AI SDK 的对话入口不支持 Responses API，并会提示切换至 Chat Completions。发送请求前还须配置非空模型名称与 API Key。[AI 助手](../features/ai.md)

### 为什么已添加的附件未被模型读取？

普通文件主要提供路径等元数据；图片还受模型视觉能力标记与大小预算约束。添加附件不表示文档、视频或音频内容均会上传并解析。应核对附件类型、模型能力与[附件限制](../features/ai.md)。

### 为什么已启用 AI 写入权限，MCP 仍提示权限不足？

AI 与 MCP 的权限独立配置。应检查 MCP 服务的写入与文件系统访问开关；局域网连接还须核对当前访问令牌。[MCP 接入](../features/mcp.md)

### 为什么通知未显示，或未提供流体云、超级岛开关？

应先检查系统通知权限与通知总开关，再核对 ROM 支持情况。流体云还需要接入标识；超级岛需要相应协议与焦点通知权限。测试结果仅表示已尝试选择通知通道，不保证系统实际展示。[通知设置](../settings/processing.md)

### 为什么清理缓存后仍有空间占用？

仍被项目或队列引用的导入副本会保留。应先处理不再需要的记录，再清理普通缓存。“图片/字体”属于独立清理类别，会移除相应自定义资源。[清理范围](../settings/advanced.md)

### 为什么启动更新后仍需手动安装？

移动端通过浏览器下载更新，macOS 打开 DMG，Linux 的自动安装路径使用 dpkg。更新流程随平台而异，部分平台仍需用户完成安装。[更新说明](../settings/about.md)

## 提交问题所需的信息

- 软件版本、操作系统/设备、FFmpeg 来源。
- 输入类型与可复现的最小步骤。
- 相关节点参数、是否硬编、实际输出路径。
- 任务错误、实际命令与相关全局日志；分享前应隐去敏感路径、API Key 与访问令牌。
