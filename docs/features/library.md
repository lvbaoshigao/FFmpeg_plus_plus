# 3.5 配置库与 FPPX 交换

经常重复的流程，适合保存为配置。配置库管理可复用的节点配置和快捷配置；FPPX 是导入、导出这些配置的交换文件。**配置不是媒体打包文件，也不是成品视频。** 换机器使用时，仍要准备媒体、字体、字幕等实际依赖。

## 三个入口，分别做什么

| 入口 | 用途 |
| --- | --- |
| 配置库新建/编辑 | 制作与维护模板 |
| 文件卡片“应用配置库” | 给当前文件应用兼容模板 |
| 项目页“导入配置” | 读取外部 FPPX，再选文件应用 |

配置库条目可以重命名、复制、编辑、导出或删除。快捷配置还支持 JSON 导入与导出，可完整保留配置项、禁用状态、节点顺序及输入输出设置。画布中的保存入口见[节点图保存](/nodes/saving)。

## 新建并应用节点配置

1. 打开配置库，点新建，填写名称。
2. 选择文件格式。旧版着重兼容历史；“新版 Beta”是模块化二进制，导出前深度校验，旧软件不能保证读取。
3. 进入编辑器配置节点并保存。模板没有当前媒体时，依赖真实文件的预览可能不可用。
4. 回项目页，在已解析文件的“更多”里选“应用配置库”。
5. 从兼容列表选择。应用会生成目标文件自己的流程副本，之后修改此文件不会直接改坏库中模板。
6. 核对输出与参数，再加入队列。

> **找不到模板不一定是丢了。** 应用列表只显示当前文件可用的配置。媒体类型不匹配、图校验失败、快捷预设转换有遗漏等，都可能阻止直接应用。先回库中修好，再试。

容器内文件的“应用到文件”只影响独立配置，容器整体运行仍用容器流程，见[项目与容器](project.md)。

## 导入外部 FPPX

1. 在配置库点导入并选择 .fppx 或快捷配置 .json。Android 选择器可能显示所有文件，请自己确认扩展名。项目页的直接导入入口使用 .fppx；JSON 先导入配置库，再从文件卡片应用。
2. 加密文件按提示输入口令。
3. 阅读版本兼容信息、介绍、警告与错误。未知节点可能触发“强制导入”确认，通常应先尝试升级。
4. 导入库后再编辑、应用；若从项目页导入，先添加目标媒体，再勾选兼容、已解析的文件。

旧配置如果没有可用节点图、也不是可转换的快速配置，项目页只能查看信息，不能直接应用。“旧版格式”与“没有节点图的传统配置”并不完全相同，请以导入结果为准。

## 导出与加密

导出时可填写介绍。新版支持 AES 加密，界面提供 AES-256（推荐）与 AES-128，需要重复确认口令。**只加密数据区，介绍文本保持明文**，不要把秘密写进介绍。

快捷配置导出默认选 JSON，也可切换为 FPPX。JSON 适合保留完整的编辑状态，支持上述 AES-256/AES-128 口令加密；FPPX 使用带媒体类型的串行节点图保留可执行步骤及重复节点。导出的音频或图片配置再应用到同类文件后，仍可使用快捷向导编辑。

随后在系统保存界面选位置。取消系统保存后，库中的配置仍保留。

> **口令自己保管。** 当前教程没有承诺找回遗忘口令的能力；分享前先与接收方确认版本和外部依赖。只想套用配置时，用兼容列表比盲目强制导入更容易发现问题。
