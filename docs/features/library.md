# 3.5 配置库与 FPPX 交换

配置库管理可复用的节点配置与快捷配置，适用于重复执行相同流程的场景。FPPX 用于导入和导出这些配置。**配置文件不等同于媒体资源包或最终输出文件。** 在其他设备上使用时，仍须准备媒体、字体、字幕等依赖。

## 操作入口与用途

| 入口 | 用途 |
| --- | --- |
| 配置库新建/编辑 | 制作与维护模板 |
| 文件卡片“应用配置库” | 给当前文件应用兼容模板 |
| 项目页“导入配置” | 读取外部 FPPX，再选文件应用 |

配置库条目可以重命名、复制、编辑、导出或删除。快捷配置还支持 JSON 导入与导出，可完整保留配置项、禁用状态、节点顺序及输入输出设置。画布中的保存入口见[节点图保存](/nodes/saving)。

## 新建并应用节点配置

1. 打开配置库，点击新建并填写名称。
2. 选择文件格式。旧版用于兼容历史版本；“新版 Beta”使用模块化二进制格式，并在导出前进行深度校验，不保证旧版软件能够读取。
3. 进入编辑器配置节点并保存。模板没有当前媒体时，依赖真实文件的预览可能不可用。
4. 返回项目页，在已解析文件的“更多”菜单中选择“应用配置库”。
5. 从兼容列表选择配置。应用会为目标文件创建流程副本，后续修改该文件的流程不会直接修改库中模板。
6. 核对输出与参数，再加入队列。

> **应用列表仅显示与当前文件兼容的配置。** 模板未显示不表示模板已丢失。媒体类型不匹配、图校验失败或快捷预设转换不完整等情况，均可能阻止应用。应返回配置库检查并修正后重试。

容器内文件的“应用到文件”只影响独立配置，容器整体运行仍用容器流程，见[项目与容器](project.md)。

## 导入外部 FPPX

1. 在配置库中点击导入，选择 .fppx 或快捷配置 .json。Android 选择器可能显示所有文件，须核对扩展名。项目页的直接导入入口使用 .fppx；JSON 须先导入配置库，再通过文件卡片应用。
2. 加密文件按提示输入口令。
3. 阅读版本兼容信息、介绍、警告与错误。未知节点可能触发“强制导入”确认，通常应先尝试升级。
4. 导入库后再编辑、应用；若从项目页导入，先添加目标媒体，再勾选兼容、已解析的文件。

旧配置如果没有可用节点图、也不是可转换的快速配置，项目页只能查看信息，不能直接应用。“旧版格式”与“没有节点图的传统配置”并不完全相同，请以导入结果为准。

## 导出与加密

导出时可填写介绍。新版支持 AES 加密，界面提供 AES-256（推荐）与 AES-128，并要求二次确认口令。**仅数据区被加密，介绍文本保持明文**；介绍中不应包含敏感信息。

快捷配置导出默认选 JSON，也可切换为 FPPX。JSON 适合保留完整的编辑状态，支持上述 AES-256/AES-128 口令加密；FPPX 使用带媒体类型的串行节点图保留可执行步骤及重复节点。导出的音频或图片配置再应用到同类文件后，仍可使用快捷向导编辑。

随后在系统保存界面选择目标位置。取消系统保存不会移除库中的配置。

> **用户须妥善保管口令。** 本教程不提供遗忘口令的恢复方法。共享配置前，应与接收方确认软件版本及外部依赖。应用配置时，应优先检查兼容列表，避免依赖强制导入绕过兼容性提示。
