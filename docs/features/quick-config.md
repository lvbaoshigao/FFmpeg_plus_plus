# 3.2 快捷配置与单文件串行处理

快捷配置适用于按顺序执行的单文件流程，例如先裁剪、再调整、最后编码。与旧版固定选项不同，当前向导支持添加处理节点、重复添加同类节点，并保留节点顺序。

## 打开向导

在[编辑器设置](../settings/editor.md)中将编辑模式设为“快速模式”，然后在项目页编辑已解析的文件，即可打开“快捷配置向导”。配置库中的快捷模板也使用此向导；没有实际媒体文件时，依赖媒体的裁剪和帧预览等功能可能不可用。

## 配置流程

1. 在“1 · 选择处理节点”中，从“可用节点”添加操作。
2. 在“处理顺序”中查看执行顺序；列表按从上到下执行。使用上移或下移调整顺序，使用移除删除不需要的步骤。
3. 选择一个节点或“下一步”，进入“2 · 配置处理节点”。此步骤使用节点编辑器的参数面板。
4. 配置当前节点后，使用上一个/下一个节点切换；需要添加步骤时，返回“选择节点”。
5. 选择“保存”仅保存配置。仅在从实际文件进入且界面显示“保存并入队”时，选择该操作才会在保存后将任务加入处理队列。
6. 前往[队列](queue.md)并选择“开始处理”。加入队列不会启动任务。

> **退出向导前确认是否保存更改。** 存在未保存更改时，系统会询问是否放弃。保存前会校验节点兼容性和参数；裁剪节点未配置有效宽高时，需先在该节点中配置裁剪区域。

## 示例：提取视频音频并调整音量

先添加提取音频节点，再添加音频处理节点。向导根据链尾的输出类型更新“可用节点”；上游输出音频时，后续节点必须支持音频输入。

两个裁剪或调整节点可以分别存在，各自有参数，不会因为“类型相同”自动合并。顺序也是配置的一部分：先裁剪再缩放，与先缩放再裁剪的尺寸基准可能不同。

## 快捷配置与节点编辑器的适用场景

| 需求 | 入口 |
| --- | --- |
| 一个文件按顺序做几步处理 | 快捷配置 |
| 同一操作用两次、参数不同 | 快捷配置，可重复添加 |
| 分支、多输出结构、逻辑门/逻辑块 | 节点编辑器 |
| 多文件合并 | 容器与节点编辑器 |
| 现有图含孤立节点、未知节点或无法串行化的结构 | 节点编辑器，不会静默截断后转换 |

多帧提取输出文件夹，不能当成一张普通图片继续接任意操作。当前快捷链允许它放在末尾，或后接“图片合成视频”。

> **“配置已保存，加入队列失败”表示配置保存成功，但入队失败。** 请检查当前文件是否仍在项目中，以及节点和参数是否有效，然后重试入队。此状态不表示配置保存失败。

快捷配置最终转换为节点图执行。模板与导出也需保留顺序，详见[配置库与 FPPX](library.md)。
