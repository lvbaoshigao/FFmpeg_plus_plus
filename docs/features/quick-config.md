# 3.2 快捷配置：用有序节点做单文件处理

快捷配置适合“先裁剪、再调整、最后编码”这样从上到下的流程。它不是旧版固定几项勾选框：当前向导可以添加处理节点、重复添加同类节点，并保留排列顺序。

## 打开向导

在[编辑器设置](../settings/editor.md)把编辑模式设为“快速模式”，回到项目页，编辑一个已解析文件，就会看到“快捷配置向导”。配置库的快捷模板也使用这个向导，但没有实际文件时，依赖媒体的裁剪、帧预览等能力可能不可用。

## 两步配好流程

1. 在“1 · 选择处理节点”里，从“可用节点”添加操作。
2. 看“处理顺序”：列表从上到下执行。用上移、下移调整顺序，用移除删掉不需要的步骤。
3. 点某个节点，或点“下一步”，进入“2 · 配置处理节点”。这里复用节点编辑器的参数面板。
4. 配好当前节点后，用上一个/下一个节点切换；需要补步骤时返回“选择节点”。
5. 点“保存”只保存配置；从实际文件进入且显示“保存并入队”时，点它才会在保存后加入处理队列。
6. 去[队列](queue.md)点“开始处理”。入队和开始执行是两件事。

> **关闭前看清是否保存。** 有未保存更改时会询问是否放弃。保存前也会校验节点兼容性和参数；裁剪节点缺少有效宽高时，需要先打开该节点配置裁剪区域。

## 例子：把视频变成音频，再调整音量

先添加提取音频节点，再添加音频处理节点。向导会根据链尾输出类型更新“可用节点”：上游已经输出音频，后面就应接能处理音频的操作。

两个裁剪或调整节点可以分别存在，各自有参数，不会因为“类型相同”自动合并。顺序也是配置的一部分：先裁剪再缩放，与先缩放再裁剪的尺寸基准可能不同。

## 什么时候回到节点编辑器

| 需求 | 入口 |
| --- | --- |
| 一个文件按顺序做几步处理 | 快捷配置 |
| 同一操作用两次、参数不同 | 快捷配置，可重复添加 |
| 分支、多输出结构、逻辑门/逻辑块 | 节点编辑器 |
| 多文件合并 | 容器与节点编辑器 |
| 现有图含孤立节点、未知节点或无法串行化的结构 | 节点编辑器，不会静默截断后转换 |

多帧提取输出文件夹，不能当成一张普通图片继续接任意操作。当前快捷链允许它放在末尾，或后接“图片合成视频”。

> **“配置已保存，加入队列失败”表示前半步已经完成。** 先检查当前文件是否还在项目里、节点和参数是否有效，再尝试入队，不要因此认定保存也丢了。

快捷配置最终转换为节点图执行。模板与导出也需保留顺序，详见[配置库与 FPPX](library.md)。
