# 3.1 项目与媒体导入

项目页用于导入媒体并配置处理流程。添加媒体后，可为单个文件配置流程，或将多个文件加入容器进行批量处理。首次执行任务的步骤见[第一个任务](/guide/first-task)。

## 添加单个文件

1. 打开“项目”，选择“添加文件”。
2. 在系统选择器中选择视频、音频或图片。桌面版也支持将扩展名受支持的文件拖入项目页。
3. 等待解析完成。此阶段由 FFprobe 读取时长、编码、分辨率和轨道等信息，不执行转码。
4. 在文件卡片中选择编辑，根据当前[编辑模式](../settings/editor.md)打开节点编辑器或快捷配置。
5. 配置并保存后，在文件卡片中选择“加入队列”，然后前往[处理队列](queue.md)启动任务。

> **解析状态与导入状态不同。** 大文件或复杂封装的解析可能需要较长时间。解析失败时，请查看[日志](logs.md)。文件显示在项目列表中，仅表示已添加，不表示解析成功或已具备处理条件。

文件选择器和桌面拖放会按常见媒体扩展名筛选文件。扩展名筛选仅用于选择入口；文件内容能否读取以及编码器能否处理，取决于 FFmpeg/FFprobe 的检测结果。桌面拖放不会自动识别没有扩展名的文件。

## 搜索、选择与移除

可使用搜索按钮按文件名筛选列表。批量操作时，进入多选并选择目标，然后使用全选、反选或删除。桌面版项目搜索的默认快捷键为 <kbd>Ctrl+F</kbd>，完整列表见[快捷键](../reference/shortcuts.md)。

移除操作管理应用中的项目和记录，不会清理原始媒体文件。应用创建的临时导入副本在不再被项目或队列引用后可以回收；原始媒体文件需由用户自行保管。

## 一组文件用容器管理

如需对一组视频应用同一流程，或将一组图片合成为视频，请从项目页的“容器”菜单创建容器。

| 创建方式 | 适用场景 | 限制与要求 |
| --- | --- | --- |
| 创建空容器 | 先创建分组，之后再添加文件 | 名称不能为空 |
| 从文件夹创建 | 一批媒体已经放在同一目录 | 只扫描所选目录这一层，不递归导入子目录；只收受支持扩展名的普通文件 |
| 从文件创建 | 媒体分散在不同位置 | 用选择器选取一批文件 |

进入容器后，可重命名、添加文件并使用排序菜单；也可在单个条目的“更多”菜单中执行上移、下移或移除。容器的编辑按钮打开**容器共用流程**。

- 普通批量处理：保存容器流程后，“全部加入队列”会给已解析文件逐个生成任务。
- 合并媒体或将图片合成为视频：选择合并任务路径。文件顺序会影响结果，入队前应核对顺序；详见[容器与批处理](/nodes/containers)。
- 给容器中的文件“应用到文件（不覆盖容器流程）”，只改该文件的独立流程。**之后从容器运行，仍使用容器流程。**

> **移动端导入入口的来源处理存在差异。** 普通“添加文件”会将没有本地路径的来源流式复制到临时目录；容器的部分选文件入口目前仅接受带本地路径的结果。云端或 SAF 来源无法通过容器入口添加时，可先复制到可访问的本地路径。输出目录也必须是 FFmpeg 可读取的真实文件系统路径。

单文件的顺序处理流程可使用[快捷配置](quick-config.md)；需要分支、多输出结构、逻辑门或容器合并时，请使用[节点编辑器](/nodes/)。已有模板可通过[配置库与 FPPX](library.md)管理。
