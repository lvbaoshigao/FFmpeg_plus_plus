# 2.12 保存、草稿、导入与导出

**保存**用于提交当前节点图，**草稿**用于恢复异常退出前的编辑状态，**导出**用于生成可交换的配置文件。三者的用途和保存范围不同，不能相互替代。

## 节点图保存流程

1. 确认源节点、处理节点和输出节点之间的数据链完整。
2. 选中“输出”，核对命名和目录。
3. 点击“保存”。程序先检查节点逻辑。
4. 如果弹出“节点逻辑错误”，关闭提示，按列出的原因修改后重试。
5. 校验成功后，节点图保存至当前文件或配置条目，编辑器退出。

常见错误包括缺少输入/输出线、媒体类型不兼容、通用节点未选类型、多路数据输入、环路和未完成的视频裁剪。具体排查见[预览与检查](preview-validation.md)。

## 返回操作与放弃更改

从非空画布返回时，可能显示“放弃更改？”确认。需要保留编辑内容时，应取消返回并保存；确认放弃会清除对应草稿。当前返回确认不精确比较实际修改状态，因此出现提示不代表参数一定发生过更改。

## 自动草稿的适用范围

| 场景 | 当前行为 |
| --- | --- |
| 普通文件/容器编辑，开启自动保存 | 编辑停止约1.2秒后防抖保存草稿 |
| 再次打开有未保存草稿的同一对象 | 自动恢复非空草稿，并给出提示 |
| 明确保存或确认放弃 | 清除对应草稿 |
| 配置库的无源文件模板编辑 | 不启用这套自动草稿保存/恢复 |
| 草稿损坏 | 忽略损坏草稿 |

> 草稿保存不会在每次编辑时调用父级正式保存。自动保存提示不表示配置库模板或文件方案已正式提交；需要保留的节点图仍须点击“保存”。

## 节点配置导入

1. 点击导入，选择扩展名为.fppx的文件。
2. 如文件加密，按提示输入口令。
3. 阅读解析错误、警告或未知节点提示。
4. 导入成功后，导入图将**替换当前画布**，不会追加到现有图。
5. 核对参数和源媒体类型，再按需要保存或导出。

导入替换会建立图级撤销快照。误导入后应立即撤销；后续编辑可能使该快照超出撤销历史容量。

快捷模式.fppx不能在此处作为节点图导入；须通过配置库导入，导入后归入“快捷配置”。

## 导出为.fppx

1. 点击导出配置，选择写入格式：旧版或新版Beta。
2. 按需要填写介绍。
3. 使用新版时，可启用加密、输入两次口令并选择AES-256或AES-128。
4. 选择目标位置完成保存。

| 选项 | 行为与限制 |
| --- | --- |
| 旧版 | 保留历史格式；不支持加密，仍执行本地图逻辑预检 |
| 新版Beta | 由后端写前校验；旧软件不能读取 |
| 加密 | 仅加密数据区，介绍仍为明文；介绍中不得写入敏感信息 |
| 取消文件保存 | 不会生成目标配置文件；须核对最终成功提示 |

导出仅用于配置交换，不打包媒体素材。字幕、封面、水印等外部文件路径须在接收设备上重新核对。

配置编写、节点字段和文件格式见[第5章：节点文件编写](/node-files/)。应用显示的大版本号不能作为推算配置文件头字段的依据。

## 未知节点的保留与执行限制

新版文件可能包含当前应用版本无法识别的节点。确认“强制导入”后，此类节点显示为未知节点，并保留原始类型ID；其参数不可正常编辑，也不能执行转码。

当前界面提示与保存校验存在差异：提示文字称未知节点“可以保存或导出”，但手动“保存”仍调用拒绝未知节点的图校验，可能无法完成。需要保留该配置时，应使用**新版格式原样导出**并核对结果。强制导入不提供未知节点的执行能力。
