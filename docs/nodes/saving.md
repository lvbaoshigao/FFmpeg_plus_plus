# 2.12 保存、草稿、导入与导出

先分清三件事：**保存**提交当前图，**草稿**帮助恢复异常退出的编辑，**导出**生成可交换的配置文件。三者不能互相替代。

## 正常保存一张图

1. 检查源、处理和输出的数据链已接通。
2. 选中“输出”，核对命名和目录。
3. 点击“保存”。程序先检查节点逻辑。
4. 如果弹出“节点逻辑错误”，关闭提示，按列出的原因修改后重试。
5. 校验成功后，图保存到当前文件或配置条目，编辑器退出。

常见错误包括缺少输入/输出线、媒体类型不兼容、通用节点未选类型、多路数据输入、环路和未完成的视频裁剪。具体排查见[预览与检查](preview-validation.md)。

## 返回时选择继续还是放弃

从非空画布返回时，可能出现“放弃更改？”确认。想保留编辑就取消返回，先保存；确认放弃会清除对应草稿。当前返回确认并不精细比较“是否真正修改”，因此不要因为出现提示就认定自己一定改过参数。

## 草稿能帮到哪里

| 场景 | 当前行为 |
| --- | --- |
| 普通文件/容器编辑，开启自动保存 | 编辑停止约1.2秒后防抖保存草稿 |
| 再次打开有未保存草稿的同一对象 | 自动恢复非空草稿，并给出提示 |
| 明确保存或确认放弃 | 清除对应草稿 |
| 配置库的无源文件模板编辑 | 不启用这套自动草稿保存/恢复 |
| 草稿损坏 | 忽略损坏草稿 |

> 草稿不会在每次编辑时调用父级正式保存。不要看到自动保存提示就以为配置库模板或文件方案已经正式提交。重要图仍要点击“保存”。

## 导入一份节点配置

1. 点击导入，选择扩展名为.fppx的文件。
2. 如文件加密，按提示输入口令。
3. 阅读解析错误、警告或未知节点提示。
4. 成功后，导入图会**替换当前画布**，不是追加到现有图。
5. 核对参数和源媒体类型，再决定保存还是导出。

导入替换会压入图级撤销快照，误导入后可立即撤销。不要连续再做很多动作才回头恢复。

快捷模式.fppx不能直接作为节点图导入这里；请到配置库导入，它会进入“快捷配置”。

## 导出为.fppx

1. 点击导出配置，选择写入格式：旧版或新版Beta。
2. 按需要填写介绍。
3. 使用新版时，可启用加密、输入两次口令并选择AES-256或AES-128。
4. 选择目标位置完成保存。

| 选项 | 使用前知道这些 |
| --- | --- |
| 旧版 | 保留历史格式；不支持加密，仍做本地图逻辑预检 |
| 新版Beta | 由后端写前校验；旧软件不能读取 |
| 加密 | 只加密数据区，介绍仍是明文；不要把秘密写进介绍 |
| 取消文件保存 | 不会产生你预期的目标配置文件；核对最终成功提示 |

导出是配置交换，不是把媒体素材打包。字幕、封面、水印等路径要在接收设备上重新核对。

需要手写配置、了解节点字段或文件格式时，请看独立的[第5章：节点文件编写](/node-files/)。不要按应用显示的大版本号自行推算配置文件头字段。

## 未知节点：可保留，不可执行

新版文件可能含当前版本认识不了的节点。确认“强制导入”后，它会显示为未知节点并保留原始类型ID；参数不可正常编辑，也不能执行转码。

当前有一处界面与校验差异：提示文字说未知节点“可以保存或导出”，但手动“保存”仍调用拒绝未知节点的图校验，可能无法完成。需要保留该配置时，用**新版格式原样导出**并核对结果；不要把强制导入当成获得新节点功能。
