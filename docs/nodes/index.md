# 2.1 先认识节点编辑器

节点编辑器适合把“先做什么、再做什么”画清楚。一个节点负责一类操作，连线决定媒体怎样往下走。先从一条简单的流程开始，熟悉后再加逻辑块。

## 第一次打开，先找这几块

| 区域 | 用来做什么 | 现在可以试什么 |
| --- | --- | --- |
| 中间画布 | 放节点、拖动、连线 | 点击“开始”节点，再点击“输出”节点 |
| 元素工具箱 | 按类别找节点、搜索、收藏 | 切到“视频”，搜索“片段截取” |
| 属性区 | 编辑当前选中的节点或逻辑块 | 选中节点后看标题，确认改的是目标节点 |
| 顶部/浮动工具栏 | 保存、导入导出、撤销重做及视图操作 | 用提示文字辨认图标 |
| 小地图与缩放控件 | 找回远处的节点、调整视野 | 画布乱了时先用“适应画布” |

桌面端有侧栏，移动端更多使用浮动按钮和弹层；位置会随屏幕方向、面板展开状态改变。手机上先点“添加节点”打开工具箱，添加后再通过属性面板调参数。

## 一条最小流程

1. 从项目里的媒体文件打开节点编辑器。
2. 保留“开始”和“输出”，添加一个处理节点，例如“片段截取”。
3. 用数据线连成：**开始 → 片段截取 → 输出**。
4. 选中“片段截取”，设好时间；选中“输出”，核对名称和目录。
5. 点击“保存”。如果出现逻辑错误，先按提示修图，再保存。

> 保存节点图只是保存处理方案。真正处理媒体要回到项目和任务队列继续操作。

## 目录里有哪些节点

| 类别 | 当前可添加的内容 | 详细说明 |
| --- | --- | --- |
| 视频 | 音视频处理、字幕烧录、片段截取、帧提取、变速、提取音频、帧率转换、视频去隔行、视频倒放、视频淡入淡出 | [2.6 视频节点](video.md) |
| 音频 | 音质调整、调整速度、调整音量、压缩动态范围、元信息编辑、音频淡入淡出、响度标准化、音频噪声门、音频降噪、静音裁剪、音频频谱图、音频波形图、音频倒放、音频均衡器 | [2.7 音频节点](audio.md) |
| 图片 | 亮度调节、添加噪点、图片降噪、通道提取、图片压缩 | [2.8 图片与通用节点](image-common.md) |
| 通用 | 元数据删除、格式转换、缩放、裁剪、旋转翻转、色彩调整、锐化降噪、叠加 | [2.8 图片与通用节点](image-common.md) |
| 控制与逻辑 | 开始、输出、13种逻辑门、4种逻辑块 | [2.10 逻辑控制](logic.md) |
| 容器 | 合并媒体、图片合成视频；仅容器上下文显示 | [2.9 容器处理](containers.md) |

“通用”不代表支持所有媒体。例如缩放支持视频和图片，叠加目前只支持视频。添加后要确认“媒体类型”。旧配置里可能出现“图片转换”“视频滤镜”等旧节点名，程序保留了兼容处理；新建时按当前目录找对应通用节点即可。
