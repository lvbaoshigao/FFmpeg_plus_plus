# 2.1 节点编辑器概述

节点编辑器用于定义媒体处理流程。每个节点对应一类操作，连线定义媒体数据的传递顺序。建立基础串行流程后，可按处理需求添加逻辑块。

## 界面区域

| 区域 | 功能 | 操作示例 |
| --- | --- | --- |
| 中间画布 | 添加、移动和连接节点 | 点击“开始”节点，再点击“输出”节点 |
| 元素工具箱 | 按类别浏览、搜索和收藏节点 | 切换到“视频”，搜索“片段截取” |
| 属性区 | 编辑当前选中的节点或逻辑块 | 选中节点后核对标题，确认编辑对象 |
| 顶部/浮动工具栏 | 保存、导入导出、撤销重做及视图操作 | 根据提示文字识别图标功能 |
| 小地图与缩放控件 | 定位当前视野外的节点、调整视野 | 使用“适应画布”查看整体布局 |

桌面端使用侧栏，移动端主要使用浮动按钮和弹层；控件位置随屏幕方向和面板展开状态变化。手机端点击“添加节点”打开工具箱，添加节点后通过属性面板设置参数。

## 最小处理流程

1. 从项目中的媒体文件打开节点编辑器。
2. 保留“开始”和“输出”，添加一个处理节点，例如“片段截取”。
3. 用数据线连成：**开始 → 片段截取 → 输出**。
4. 选中“片段截取”，设置起止时间；选中“输出”，核对名称和目录。
5. 点击“保存”。出现逻辑错误时，按提示修正节点图后重新保存。

> 保存节点图仅保存处理方案。执行媒体处理需要返回项目和任务队列继续操作。

## 节点分类

| 类别 | 当前可添加的内容 | 详细说明 |
| --- | --- | --- |
| 视频 | 音视频处理、字幕烧录、片段截取、帧提取、变速、提取音频、帧率转换、视频去隔行、视频倒放、视频淡入淡出 | [2.6 视频节点](video.md) |
| 音频 | 音质调整、调整速度、调整音量、压缩动态范围、元信息编辑、音频淡入淡出、响度标准化、音频噪声门、音频降噪、静音裁剪、音频频谱图、音频波形图、音频倒放、音频均衡器 | [2.7 音频节点](audio.md) |
| 图片 | 亮度调节、添加噪点、图片降噪、通道提取、图片压缩 | [2.8 图片与通用节点](image-common.md) |
| 通用 | 元数据删除、格式转换、缩放、裁剪、旋转翻转、色彩调整、锐化降噪、叠加 | [2.8 图片与通用节点](image-common.md) |
| 控制与逻辑 | 开始、输出、13种逻辑门、4种逻辑块 | [2.10 逻辑控制](logic.md) |
| 容器 | 合并媒体、图片合成视频；仅容器上下文显示 | [2.9 容器处理](containers.md) |

“通用”类别中各节点支持的媒体类型不同。例如缩放支持视频和图片，叠加目前仅支持视频。添加节点后须确认“媒体类型”。旧配置可能包含“图片转换”“视频滤镜”等旧节点名，程序保留了兼容处理；新建流程时应从当前目录选择对应的通用节点。
