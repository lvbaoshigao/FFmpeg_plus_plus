# 2.10 逻辑门与逻辑块

逻辑门通过0/1信号控制处理步骤是否执行；逻辑块用于组织一组处理节点，并定义重复、选择或条件执行规则。两者的作用不同。添加逻辑控制前，应先验证普通数据链能够执行。

## 逻辑门使能控制示例

1. 建立数据链：**开始 → 片段截取 → 帧率转换 → 输出**。
2. 从“控制与逻辑”添加“恒1”。
3. 使用控制线将恒1输出连接到“片段截取”的使能输入，并保留原有数据连线。
4. 保存并执行测试任务；恒1表示启用。
5. 验证禁用行为时，可将控制源改为恒0，使中间步骤跳过；不得因此禁用最后的处理步骤。

> 逻辑线不传递媒体数据，不能替代数据输入。将恒0连接到唯一的最后处理步骤不能实现任务“暂停”；当前实现会因缺少最终产物而构建失败。

## 当前13种逻辑门

| 门 | 输入数 | 输出含义 |
| --- | --- | --- |
| 与AND | 2 | 所有输入都为1才输出1 |
| 或OR | 2 | 任一输入为1就输出1 |
| 非NOT | 1 | 输入取反 |
| 与非NAND | 2 | 与的取反 |
| 或非NOR | 2 | 或的取反 |
| 异或XOR | 2 | 两输入不同为1 |
| 同或XNOR | 2 | 两输入相同为1 |
| 恒1 | 0 | 一直输出1 |
| 恒0 | 0 | 一直输出0 |
| 时间触发器 | 0 | 系统日期/时间符合设置时为1 |
| 随机门 | 0 | 根据概率和节点ID哈希判定 |
| 文件名匹配 | 0 | 对表单中的待测文本执行包含比较 |
| 文本后缀匹配 | 0 | 对表单中的待测文本执行后缀比较 |

须按输入数量连接全部输入端口。悬空和未知值通常按启用处理，不能依赖其阻止任务执行。多个逻辑门连接到同一使能端时按“或”组合；需要“全部满足”时，须先通过AND组合，再连接使能端。

### 时间触发器

在属性中选择日期、开始时间和结束时间。日期为空表示每天；结束时间为空时，匹配开始时刻所在的分钟。时间区间支持跨天范围，例如22:00–06:00。

界面初始显示09:00，但新建逻辑门不一定已保存开始时间；须明确选择并确认时间。时间门根据构建执行计划时的系统时间求值，**不提供定时功能，也不会在队列中等待目标时间后启动**。

### 随机门

默认概率为50%，范围为0–100%。当前结果通过比较节点ID哈希与概率得出；相同ID和概率通常产生相同结果。复制或重新载入导致ID变化时，结果可能变化。该门不逐帧重新取随机值，也不负责选择性循环中的随机操作选择。

### 文件名与后缀门

当前界面要求填写“待测文本”和“匹配文本”；执行器忽略大小写，比较这两段配置文字，**不会自动填入当前处理文件的文件名**。例如待测文本movie.mp4与后缀.mp4匹配。

需要根据各输入文件的扩展名或文件名筛选时，须使用下文的“条件”逻辑块。

## 逻辑块创建步骤

1. 在工具箱“控制与逻辑”中选择循环、选择性循环、分组或条件。
2. 桌面可双击逻辑块工具项进入框选，手机点按后进入框选。
3. 在画布上框选需要包含的处理节点。循环类会继续显示次数设置对话框；分组和条件直接创建。
4. 点击逻辑块的编辑入口，在属性中完成设置。

同一节点不能属于多个逻辑块，不支持通过重叠逻辑块创建嵌套循环。源节点、输出节点及以源类型实现的逻辑门不能加入此类处理块。

| 逻辑块 | 执行语义 | 初始设置 |
| --- | --- | --- |
| 循环 | 重复执行块内步骤 | 次数对话框初值10 |
| 选择性循环 | 重复执行，并选择参与的块内步骤 | 新建默认全部执行 |
| 分组 | 仅组织和整体移动，不增加执行次数 | 执行一次 |
| 条件 | 按源输入文件属性决定执行/跳过 | 扩展名等于mp4，不满足跳过 |

逻辑块可整体拖动、折叠/展开。点击逻辑块上的×会删除逻辑块，**不会同时删除块内处理节点**；原节点及其普通连线仍保留。逻辑块上的端口仅作视觉提示，不能作为普通数据端口连接。

## 循环次数、累积与失败策略

- 固定次数：1–10000；默认10。
- 区间：设置起始、结束和步长。例如3到10、步长2，对应3、5、7、9，共4轮，不表示执行10轮。
- 链式累积：默认关闭；关闭时每轮从原始输入开始，开启时下一轮使用上一轮的输出。
- 某轮失败：默认中止整个任务，可改为跳过并继续；重试初值为0，范围为0–10。

迭代变量包括{i}（当前序号）、{i0}（从0起的轮次）、{n}（总轮数）、{i:03}（补零序号）。例如参数文字中的frame_{i:03}.jpg对应frame_001.jpg等。使用序号模板时须确保文件名唯一；程序不会再为此类名称追加_loop_N后缀。

循环的每一轮都可能执行实际媒体处理。应先使用短素材验证2轮，再增加循环次数。

## 选择性循环的边界

可选模式为全部执行、手动选择和随机选择。手动模式下须勾选参与处理的节点。

> **“随机选择”当前尚未实现，行为等同全部执行。** 新建逻辑块默认全部执行。手动模式未勾选任何节点时，执行器不会按“全部禁用”处理；使用手动选择时须至少勾选一个节点，并核对最终步骤。

手动选择中未勾选最后处理步骤时，该步骤仍会执行并产生警告。当前实现通过此行为保留最终输出链，因此不能用此模式实现“完全不产出”的控制方案。

## 条件块配置

示例：仅对MP4源执行中间的调色步骤，其他格式跳过该步骤。

1. 将调色节点加入“条件”块，并在下游另接一个始终执行的处理节点及输出节点。
2. 字段选择扩展名，比较方式选择等于，目标值填写mp4，不含前导点。
3. “不满足时”保留“跳过框内操作”。
4. 分别使用MP4和另一格式执行测试任务，并检查任务日志。

可用判断字段为扩展名、文件名、文件大小、完整路径和所在目录。文件大小单位为字节，10485760表示10 MiB。字符串比较忽略大小写；大于、小于等数值比较仅适用于文件大小。

条件的判断对象是任务的**源输入文件**，而非中间临时产物；不能用于检测上一步输出的尺寸、时长或文件名。条件块包含最后处理步骤时，该步骤始终执行并产生警告；“不满足时中止”也不对该末步生效。

## 当前实现限制

- 普通节点的状态输出直接连接普通节点使能输入时，画布允许创建连线，但保存校验会拒绝。参见[连线限制](connections.md)。
- 执行器可能将若干兼容节点合并为一次处理。若合并后的节点分属不同逻辑块，仅应用其中一个逻辑块的参数并产生警告；须将相关节点放入同一逻辑块，或调整步骤划分。
- 探测仅显示设计时信号，不表示实际FFmpeg任务的实时状态；值为1不表示处理已成功。
