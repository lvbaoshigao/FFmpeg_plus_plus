# 2.13 完整处理流程实例

本页实例均采用串行数据链，节点名称与工具箱一致。通用节点须选择媒体类型。每例应先使用短素材验证结果，再处理正式文件。

## 例一：截取20秒、转换为25 fps并应用画面淡入淡出

**开始 → 片段截取 → 帧率转换 → 视频淡入淡出 → 输出**

1. 打开一段超过30秒的视频的节点编辑器。
2. 在“视频”类别添加上述3个处理节点，并按顺序连接数据线。
3. 片段截取：开始00:00:10.000，结束00:00:30.000。
4. 帧率转换：选25 fps。
5. 视频淡入淡出：淡入2秒、淡出2秒、淡出位置自动。
6. 输出：选择添加后缀，例如_clip25，并指定测试视频目录。
7. 保存后返回项目/队列运行，确认输出时长约20秒，并检查画面过渡和声音。

**要点：** 自动淡出按截取后的时长推算；视频淡入淡出不改变声音。需要音频淡出时，须另行配置音频处理。

## 例二：视频音轨提取、降噪与响度标准化

**开始 → 提取音频 → 音频降噪 → 响度标准化 → 输出**

1. 准备包含音轨的短视频。
2. 提取音频选择M4A、AAC；仅测试部分内容时，可选择片段提取并设置有效时间。
3. 音频降噪先保持12 dB和−30 dB噪声底。
4. 响度标准化先保持−16 LUFS、−1.5 dBTP、11 LU。
5. 输出添加后缀_voice，保存并运行，再打开产物试听。

**结果比较：** 先仅提取音频并运行一次，再添加降噪和响度处理并重新运行，比较人声细节。出现水声、金属感等明显的降噪伪影或音色失真时，应先降低降噪量。提取音频中的播放按钮仅试听选段，不包含后续两步的完整效果。

## 例三：生成音频波形图片

**开始 → 音频波形图 → 图片压缩 → 输出**

1. 从音频文件进入编辑器，添加音频波形图。
2. 保持1280×720、PNG，或按需修改宽高（每边64–4096）。
3. 添加图片压缩，选WebP、质量75。
4. 为输出设置可区分的名称，再保存并运行。
5. 检查生成的是一张图片，扩展名与实际格式一致。

需要频率分布图时，将“音频波形图”替换为“音频频谱图”。两者均输出不含声音的静态图片；该流程不能生成带声音的可视化视频。

## 例四：图片尺寸减半并转换为WebP

**开始 → 缩放（图片） → 图片压缩 → 输出**

1. 打开图片，添加“通用 → 缩放”。
2. 媒体类型选择图片，缩放模式选择指定倍数，填写或选择0.5。
3. 图片压缩选WebP、质量75。
4. 输出命名加_small后缀，保存运行。
5. 检查实际宽高和图像细节。输出尺寸会对齐到偶数像素；原尺寸为奇数时，结果不会保留尺寸减半产生的小数像素。

仅需转换格式并设置较高质量时，可改用“格式转换（图片）”，选择WebP并设置质量。原图为PNG且保持原格式时，调整质量滑块不保证改变文件体积。

## 例五：将编号图片合成为图像序列视频

**容器开始 → 图片合成视频 → 输出**

1. 将图片放入同一容器，并按所需顺序排列编号。
2. 打开容器节点编辑器，选择“容器 → 图片合成视频”。
3. 图片顺序按编号，帧率10 fps；输出MP4、H.264。
4. 保存并运行，检查图片顺序和时长。

例如60张图片以10 fps合成时，时长约为6秒。需要使用1,3,2等顺序时，手动列表必须包含全部图片，且编号不得重复。该节点按每张1/fps秒合成序列，不提供逐张设置停留秒数的时间表。

## 例六：按MP4源扩展名控制中间调色步骤

**开始 → 色彩调整（视频） → 帧率转换 → 输出**

1. 建立串行数据链，并将帧率转换设为始终执行的最后一个处理节点。
2. 在色彩调整中勾选所需效果，例如黑白。
3. 添加“条件”逻辑块，仅包含色彩调整，不包含最后的帧率转换。
4. 字段选扩展名，比较选等于，目标值填mp4，不满足时跳过。
5. 分别用MP4和另一兼容视频文件测试，检查日志和输出。

**末步限制：** 当前条件块包含最后处理步骤时，该步骤不会被跳过，并会产生警告。此布局仅对中间步骤设置条件，以避免末步豁免影响条件验证。

## 交付前检查

- 点击保存，确认通过结构检查。
- 选中输出，核对名称、目录和实际输出格式。
- 执行短任务，检查画面、声音和日志警告。
- 需要复用时导出配置，并在接收设备上重新核对字幕、水印、封面等外部文件路径。

无法定位失败步骤时，应使用最小流程“开始 → 一个处理节点 → 输出”验证，再逐项恢复处理节点。相关限制见[预览与检查](preview-validation.md)和[保存与交换](saving.md)。
