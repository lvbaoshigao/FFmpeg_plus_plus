# 2.13 跟着做几条完整流程

这些例子都从串行链开始。节点名就是工具箱里的名称；通用节点记得选媒体类型。每例都先用短素材，确认结果后再换正式文件。

## 例一：截取20秒，统一25 fps并让画面淡入淡出

**开始 → 片段截取 → 帧率转换 → 视频淡入淡出 → 输出**

1. 打开一段超过30秒的视频的节点编辑器。
2. 在“视频”类别添加上面3个处理节点，按顺序接数据线。
3. 片段截取：开始00:00:10.000，结束00:00:30.000。
4. 帧率转换：选25 fps。
5. 视频淡入淡出：淡入2秒、淡出2秒、淡出位置自动。
6. 输出：选择添加后缀，例如_clip25，并指定试片目录。
7. 保存，回到项目/队列运行，检查成片约20秒、画面过渡和声音。

**要点：** 自动淡出按截取后的时长推算；视频淡入淡出不改声音。想让声音也淡出，不要以为这个节点已经完成了音频处理。

## 例二：从视频取声音，再做响度整理

**开始 → 提取音频 → 音频降噪 → 响度标准化 → 输出**

1. 先准备有音轨的短视频。
2. 提取音频选择M4A、AAC；要试局部可先选片段提取并设置有效时间。
3. 音频降噪先保持12 dB和−30 dB噪声底。
4. 响度标准化先保持−16 LUFS、−1.5 dBTP、11 LU。
5. 输出添加后缀_voice，保存并运行，打开产物试听。

**怎么比较：** 先只提取音频运行一次，再加降噪和响度处理运行一次，比较人声细节。若有明显水声/金属感，先降低降噪量。提取音频里的播放按钮只试听选段，不含后面两步的完整效果。

## 例三：把音频做成可分享的波形图片

**开始 → 音频波形图 → 图片压缩 → 输出**

1. 从音频文件进入编辑器，添加音频波形图。
2. 保持1280×720、PNG，或按需要改宽高（每边64–4096）。
3. 添加图片压缩，选WebP、质量75。
4. 输出使用容易区分的名称，保存运行。
5. 检查生成的是一张图片，扩展名与实际格式一致。

想看频率分布时，把“音频波形图”换成“音频频谱图”。两者都不含声音；想做带声音的可视化视频，不能仅靠这条图声称已经完成。

## 例四：图片减半并转WebP

**开始 → 缩放（图片） → 图片压缩 → 输出**

1. 打开图片，添加“通用 → 缩放”。
2. 媒体类型选图片，缩放模式选指定倍数，填/选0.5。
3. 图片压缩选WebP、质量75。
4. 输出命名加_small后缀，保存运行。
5. 看实际宽高与细节。输出会对齐偶数像素，奇数尺寸不必期待精确到原尺寸的一半小数。

如果只是换格式、希望较高质量，可以改用“格式转换（图片）”选WebP并设置质量；如果原图是PNG且保持原格式，质量滑块不一定带来体积变化。

## 例五：把编号图片合成为图像序列视频

**容器开始 → 图片合成视频 → 输出**

1. 把图片放入一个容器，按需要排好编号。
2. 打开容器节点编辑器，选择“容器 → 图片合成视频”。
3. 图片顺序按编号，帧率10 fps；输出MP4、H.264。
4. 保存并运行，检查图片顺序和时长。

例如60张图、10 fps，约6秒。若要改成1,3,2等顺序，手动列表必须包含所有图片且不重复。这个节点按每张1/fps秒拼序列，不提供单张几秒的独立停留时间表。

## 例六：只对MP4源应用中间的调色

**开始 → 色彩调整（视频） → 帧率转换 → 输出**

1. 先把串行数据链接好，让帧率转换始终作为最后一个处理节点。
2. 在色彩调整里勾一个明确效果，例如黑白。
3. 添加“条件”逻辑块，只框住色彩调整，不框最后的帧率转换。
4. 字段选扩展名，比较选等于，目标值填mp4，不满足时跳过。
5. 分别用MP4和另一兼容视频文件测试，检查日志和输出。

**为什么后面留一步：** 当前条件块覆盖最后处理步骤时，最后步骤不会被跳过并会警告。这个布局把条件放在中间，避免把末步豁免误当成条件没有保存。

## 每次交付前过一遍

- 点保存通过结构检查。
- 选中输出，核对名称、目录和实际格式。
- 跑一个短任务，看画面/听声音，检查日志警告。
- 要复用时导出配置；接收设备上重新核对字幕、水印、封面等外部路径。

不知道卡在哪一步，就退回最简单的“开始 → 一个处理节点 → 输出”，确认后再一项项加回去。相关边界见[预览与检查](preview-validation.md)和[保存与交换](saving.md)。
