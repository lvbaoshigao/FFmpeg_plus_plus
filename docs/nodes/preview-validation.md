# 2.11 预览、探测与错误检查

编辑器中的“预览”功能具有不同的内容范围。使用前须确认预览入口及其数据来源；源素材画面不能代表整条流程的最终输出。

## 预览内容与适用范围

| 入口 | 实际内容 | 不涵盖的内容 |
| --- | --- | --- |
| 桌面单击工具箱元素 | 临时节点的参数表单 | 不能确认节点已添加，也不能确认参数会用于新节点 |
| 片段截取、帧提取 | 指定源时间位置的画面 | 前面所有处理后的完整效果 |
| 视频/图片裁剪工具 | 参考画面、裁剪区域与坐标 | 最终编码画质或整条管线输出 |
| 提取音频的播放按钮 | 临时提取所选音频片段进行试听 | 后续降噪、音量、均衡等完整处理效果 |
| 字幕样式示例 | 界面中的字体/颜色示例文字 | 真实视频上的最终排版和完整字幕时序 |
| 输出节点“输出预览” | 预计文件名和目录文字 | 不表示已生成文件，也不显示实际成片画面 |

> 当前编辑器不提供整条流水线的统一实时渲染预览。确认最终效果须先保存，使用短素材执行任务，再打开实际产物检查。

## 预览空白的排查步骤

1. 确认当前编辑器关联实际源文件；配置库空模板没有可用于取帧的媒体。
2. 确认源文件路径仍有效，且FFmpeg可用。
3. 设置有效时间或帧号，再执行提取/刷新。
4. 图片裁剪需要可访问的源图片；上游运行时生成的图片可能无法即时预览，可先按已知尺寸手动填写参数。
5. 使用最小处理链验证源文件和工具的可用性，再逐步恢复其他节点；增加节点不能替代源文件和工具检查。

音频试听时，若源音频编码与临时M4A不兼容，可能导致提取失败。试听失败不表示整条正式输出链无效；正式输出仍须选择兼容的编码与格式。

## 探测模式操作步骤

1. 开启工具栏“探测模式”。也可在快捷键设置中配置按键；默认未绑定。
2. 桌面将鼠标移到端口上；触屏按下并移动到端口附近。
3. 查看提示中的媒体类型，或逻辑门的输入、输出值。
4. 连线影响辨识时，可暂时隐藏逻辑线；此操作仅改变显示，不断开连线或禁用逻辑。

| 提示 | 当前含义 |
| --- | --- |
| 数据输入/输出：video、audio、image | 设计图中的媒体类型 |
| 状态输出：1（成功） | 固定设计值，不表示实时任务已成功 |
| 使能输入：1（悬空默认） | 端口默认启用提示，不表示完整使能网络的运行结果 |
| 逻辑门：0/1 | 基于当前画布输入的门值推算 |
| ? | 悬空/环路/未知，或时间、随机、文本门在设计探测中不计算 |

探测中的“成功1”不能替代任务日志。时间、概率和文本条件的最终判定，应以正式任务构建与执行结果为准。

## 保存校验范围

保存操作检查节点结构和部分参数。发现错误时，列出错误并停止本次保存。

| 错误类别 | 处理方法 |
| --- | --- |
| 缺少源、输出、输入线或输出线 | 补全数据链，删除未使用的孤立处理节点 |
| 多条数据输入 | 改成串行；多文件合并用容器的合并节点 |
| 类型不兼容 | 检查媒体类型；视频须先提取音频，再连接音频节点 |
| 存在循环连线 | 删除环路连线；重复操作改用逻辑块 |
| 通用节点未选媒体类型 | 选中该节点，在属性顶部选择媒体类型 |
| 视频裁剪没有区域 | 提取帧、打开选择工具并保存选区 |
| 截取时间超出上游范围 | 根据上游片段时长重新填写时间 |
| 逻辑块重复引用/包含源或输出 | 调整块的节点归属，仅包含处理节点 |

通过校验不保证所有外部路径、编码器、硬件及媒体内容均可成功处理。水印路径为空时，相关节点还可能被跳过而不报错；需要水印时须单独核对路径和输出。

## 调试信息与日志排查

设置中的调试模式会记录更多节点添加、草稿保存、AI工具调用等信息。排查问题时，应记录源类型、最小节点链、错误原文和发生步骤，并结合日志分析。调试模式不执行节点图测试，也不将设计时端口值转换为实时执行状态。
