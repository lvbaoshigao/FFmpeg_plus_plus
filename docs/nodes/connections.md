# 2.4 节点连接与流程约束

数据线定义媒体数据的来源和传递目标；控制线决定处理步骤是否执行。应先建立完整数据链，再添加控制线并逐步检查。

## 串行数据链连接步骤

1. 找到“开始”右侧的数据输出端口。
2. 从该端口拖出连线，在处理节点左侧的数据输入端口处松开。
3. 将处理节点的数据输出连接至“输出”的数据输入。
4. 松开后确认连线连接到端口。拖至节点卡片中部不能完成连接。
5. 保存以触发校验。缺少输入或输出的孤立节点会导致错误；须删除未使用的节点，或补全其连线。

例如：**开始 → 片段截取 → 帧率转换 → 输出**。该链先截取片段，再转换帧率；两步操作不分别从原视频独立获取数据。

## 端口类型与用途

普通处理节点的端口通常上下排列：上方为媒体数据端口，下方为逻辑控制端口。识别端口时，应结合位置、提示和探测信息，不能仅依据主题颜色。

| 连接方式 | 用途 |
| --- | --- |
| 数据输出 → 数据输入 | 将视频、音频或图片传递至下一处理步骤 |
| 逻辑门输出 → 处理节点使能输入 | 用0/1决定是否执行处理步骤 |
| 逻辑门输出 → 另一逻辑门输入 | 组合布尔条件 |
| 处理节点状态输出 → 逻辑门输入 | 向逻辑门提供状态信号；探测显示设计值，非实时任务结果 |

源节点没有使能输入或状态输出。逻辑门只有控制端口，不接收媒体数据。常量门、时间触发器、随机门和文本匹配门没有控制输入端口。

## 媒体类型兼容性

视频数据只能连接至接受视频的节点，图片数据只能连接至接受图片的节点。改变媒体类别时，须使用相应转换节点：

- 视频 → **提取音频** → 音频节点。
- 音频 → **音频频谱图或波形图** → 图片节点；视频先经过“提取音频”。
- 图片容器 → **图片合成视频** → 视频节点。

“开始”节点可能根据第一条处理连线锁定媒体类型。配置模板中，同一源不能同时作为音频源和不兼容的图片源使用。通用节点须确认“媒体类型”。

## 数据图结构与并行处理限制

> **优先使用串行链。** 普通节点仅支持一条数据输入。将两条分支连接到同一节点不会混流，且会被校验拒绝。拼接多个文件须在容器中使用“合并媒体”；分支汇合的数据图不能替代该节点。

部分音视频处理可在执行计划中合并，但许多节点不支持同层并行。建立流程时，应优先按处理顺序串联节点。出现“不能与其他操作并行”提示时，须按提示调整为串行结构。

节点图还须满足以下条件：

- 至少有源文件节点和输出节点，源必须能够到达输出。
- 不允许节点自连接或形成连接环路。重复处理须使用逻辑块，不能使用环形数据连线。
- 不能引用已不存在的节点。
- 通用节点须选择媒体类型，才能作为已配置完成的步骤。

## 连线删除与重新连接

桌面端右键点击连线，或手机端长按连线，选择“删除连线”；随后从端口重新拖动连线至目标端口。删除的连线可通过图级撤销恢复。

## 状态输出直连使能输入的校验限制

当前画布允许将普通节点的状态输出直接连接到另一普通节点的使能输入，但保存校验要求使能输入来自逻辑门，因此此类连线无法通过保存校验。

应调整为：**状态输出 → 逻辑门输入 → 目标使能输入**，并核对逻辑门的输入数量和逻辑含义。画布允许创建连线，不表示该连线已通过保存校验。
