# 2.4 把节点连成可运行的流程

数据线回答“媒体从哪里来、交给谁”；控制线回答“这一步是否执行”。先把数据线接通，再加控制线会更容易排错。

## 先接一条串行链

1. 找到“开始”右侧的数据输出端口。
2. 从它拖出连线，松到处理节点左侧的数据输入端口。
3. 再把处理节点的数据输出接到“输出”的数据输入。
4. 松手后确认线真的落在端口上。拖到节点卡片的中间不算完成连接。
5. 保存检查。没有输入或输出的孤立节点也会报错，没用到的节点请删除或接好。

例如：**开始 → 片段截取 → 帧率转换 → 输出**。这表示先截取，再转换帧率，并非两种操作同时从原视频独立取数据。

## 端口怎么认

普通处理节点的端口通常上下排列：上面用于媒体数据，下面用于逻辑控制。以端口位置、提示及探测信息为准，不要只依赖主题颜色。

| 连接方式 | 用途 |
| --- | --- |
| 数据输出 → 数据输入 | 把视频、音频或图片送到下一步 |
| 逻辑门输出 → 处理节点使能输入 | 用0/1决定是否执行处理步骤 |
| 逻辑门输出 → 另一逻辑门输入 | 组合布尔条件 |
| 处理节点状态输出 → 逻辑门输入 | 给逻辑门提供状态信号；探测里显示的是设计值，非实时任务结果 |

源节点没有使能输入或状态输出。逻辑门只有控制端口，不接收媒体数据。常量门、时间触发器、随机门和文本匹配门没有控制输入端口。

## 媒体类型必须接得上

视频只能接接受视频的节点；图片只能接图片处理节点。需要换媒体类别时，用明确的转换入口：

- 视频 → **提取音频** → 音频节点。
- 音频 → **音频频谱图或波形图** → 图片节点；视频先经过“提取音频”。
- 图片容器 → **图片合成视频** → 视频节点。

“开始”节点可能按第一条处理线锁定媒体类型。配置模板里尤其要留意：同一个源不能一边当音频、一边又当不兼容的图片源。通用节点先确认“媒体类型”。

## 当前支持到哪一步

> **优先用串行链。** 一个普通节点只能有一条数据输入。两条分支接回同一个节点不会自动混流，会被校验拒绝。想拼接多个文件，请在容器中使用“合并媒体”，不要画一个菱形来代替。

部分音视频处理可以在执行计划中合并，但许多节点不支持同层并行。第一次搭图时，把操作按顺序串起来最稳妥；碰到“不能与其他操作并行”就按提示拆成串行。

还需要满足：

- 至少有源文件节点和输出节点，源必须能够到达输出。
- 不能自己连自己，也不能绕一圈连回来。循环请用逻辑块，不是环形数据线。
- 不能引用已不存在的节点。
- 没有选择媒体类型的通用节点不能作为已配置完成的步骤。

## 删除或改接一条线

桌面右键连线、手机长按连线，选择“删除连线”；然后从端口重新拖到新目标即可。删除连线可用图级撤销恢复。

## 一处需要避开的控制连线

当前画布允许把普通节点状态端直接接到另一普通节点使能端，但保存校验仍要求使能端来自逻辑门。你可能画得出线，却保存失败。

可改成：**状态输出 → 逻辑门输入 → 目标使能输入**，并核对门的输入数量和逻辑含义。不要把“画得出来”当成“已经通过校验”。
