# 2.3 选中节点，改好参数

先点画布里的节点，再改属性。工具箱的节点预览和画布中的实际节点很像，动手前看一眼标题和选中高亮，能避免改错地方。

## 一次参数修改怎么完成

以“调整音量”为例：

1. 点击画布中的“调整音量”节点。
2. 在属性区把音量从0 dB调到需要的值，例如先试−3 dB。
3. 点击别的节点，再选回来，确认数值仍在。
4. 继续编辑其他步骤；最后用编辑器“保存”提交整张图。

大部分参数在滑块移动、选项切换或文字输入时就更新到当前画布，不需要再找一个统一的“应用参数”按钮。裁剪工具等独立窗口有自己的“保存/取消”，要先完成窗口中的操作，再保存整张图。

> 这里的“已更新”指当前编辑会话。它不等于已保存到文件配置或配置库，区别见[保存与草稿](saving.md)。

## 通用节点先选媒体类型

“格式转换”“裁剪”等节点上方有“媒体类型（必选）”。

1. 按当前处理链选择视频、图片或音频。
2. 下方会换成对应媒体的参数表单。
3. 再检查上下游的类型是否匹配。

部分连线会按上游自动回填媒体类型，但不要依赖它代替检查。主动切换媒体类型会清除不适用于新类型的参数；例如把“格式转换”从视频改成图片，不会保留一整套视频编码选项。

## 自定义名称和颜色

普通媒体节点属性下方的“自定义”区可以填写节点名称、选择颜色。名称是辅助标注，例如“手机压缩版”“保留中间20秒”，不会把该节点变成另一种处理功能。预览用的临时节点不显示这一区域。

建议在重复节点多的时候命名：两处“缩放”分别叫“生成小图”和“恢复输出尺寸”，看图会更轻松。

## 开始与输出也要检查

| 节点 | 重点看什么 |
| --- | --- |
| 开始 | 文件名、时长、分辨率、编码等源信息；源文件从你打开编辑器的文件或容器取得 |
| 输出 | 输出格式、命名方式、后缀/名称、输出目录以及路径预览 |

“输出”默认保持格式、保持原名，后缀输入的初始文本为_processed，但只有选择“添加后缀”后才按这个后缀命名。输出目录留空时跟随设置；设置也没给目录时使用源文件目录。

图片或音频要换格式，优先在对应“格式转换”、图片压缩、音频可视化等处理节点里设置。不要只改文件名的扩展名来代替转换。

## 删掉节点前先看选区

- 桌面右键节点、手机长按节点，可以复制、粘贴或删除。
- 选中了多个节点时，菜单还会提供“删除选中”。
- 删除节点会一起删除与它相连的线，并清理逻辑块里的引用。
- 只想取消某项效果时，可以先断开和重接数据线，再删除节点；不要让两头留下断链。

## 参数和撤销的边界

编辑器提供图级撤销，但普通参数表单的修改并非都单独建立撤销快照。不要把Ctrl+Z当成每个参数都能逐字倒退的保证。重要数值可以先记下，或在修改前导出一份配置。文本框有焦点时，复制粘贴和撤销优先用于文字编辑。
