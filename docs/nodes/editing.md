# 2.3 节点选择与参数编辑

编辑参数前，先选择画布中的目标节点。工具箱预览与实际节点使用相似的属性界面，须通过属性标题和画布选中高亮确认编辑对象。

## 参数修改流程

以“调整音量”为例：

1. 点击画布中的“调整音量”节点。
2. 在属性区将音量从0 dB调整为目标值，例如−3 dB。
3. 切换到其他节点，再重新选择该节点，核对参数值。
4. 完成其他步骤的编辑后，点击编辑器“保存”提交整个节点图。

大部分参数在移动滑块、切换选项或输入文字时更新至当前画布，无须通过统一的“应用参数”按钮提交。裁剪工具等独立窗口使用各自的“保存/取消”操作；须先完成窗口内操作，再保存整个节点图。

> “已更新”仅表示当前编辑会话中的状态，不表示已保存到文件配置或配置库。两者区别见[保存与草稿](saving.md)。

## 通用节点的媒体类型设置

“格式转换”“裁剪”等节点上方有“媒体类型（必选）”。

1. 按当前处理链选择视频、图片或音频。
2. 下方参数表单随所选媒体类型切换。
3. 检查上下游媒体类型是否匹配。

部分连线会根据上游节点自动回填媒体类型，仍须核对回填结果。主动切换媒体类型会清除不适用于新类型的参数；例如将“格式转换”从视频切换为图片时，不会保留视频编码选项。

## 自定义名称和颜色

普通媒体节点属性下方的“自定义”区用于设置节点名称和颜色。名称仅作辅助标注，例如“手机压缩版”“保留中间20秒”，不改变节点的处理功能。临时预览节点不显示该区域。

存在多个同类节点时，应按用途命名。例如将两处“缩放”分别命名为“生成小图”和“恢复输出尺寸”，以区分其处理目的。

## 开始与输出节点检查

| 节点 | 核对内容 |
| --- | --- |
| 开始 | 文件名、时长、分辨率、编码等源信息；源文件取自打开编辑器时所选的文件或容器 |
| 输出 | 输出格式、命名方式、后缀/名称、输出目录以及路径预览 |

“输出”默认保持格式和原名。后缀输入框的初始文本为_processed，仅在选择“添加后缀”后用于命名。输出目录留空时使用设置中的目录；设置中也未指定目录时，使用源文件目录。

更改图片或音频格式时，应在对应“格式转换”、图片压缩、音频可视化等处理节点中设置。仅修改文件扩展名不能完成格式转换。

## 节点删除与选区检查

- 桌面右键节点、手机长按节点，可以复制、粘贴或删除。
- 选中多个节点时，菜单提供“删除选中”。
- 删除节点会同时删除相关连线，并清理逻辑块中的引用。
- 移除某项处理效果时，可先断开并重新连接其上下游数据线，再删除节点；删除后须确认数据链完整。

## 参数和撤销的边界

编辑器提供图级撤销，但普通参数表单的修改并非都单独建立撤销快照；Ctrl+Z不保证逐项或逐字恢复所有参数。修改前应记录重要数值，或导出配置作为备份。文本框获得焦点时，复制、粘贴和撤销优先用于文字编辑。
