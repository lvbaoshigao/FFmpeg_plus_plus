# 2.5 画布操作与批量整理

画布提供视野移动、多节点选择、处理链复制和自动布局功能。节点数量增加时，可使用这些操作整理节点位置与连线。

## 桌面与触屏操作对照

| 操作 | 桌面端 | 移动端 |
| --- | --- | --- |
| 移动节点 | 拖动节点主体 | 用手指拖动节点主体 |
| 移动画布 | 按住右键拖动空白区域 | 在空白处拖动视野 |
| 缩放 | 缩放控件；支持的触控板/滚轮手势 | 双指缩放或缩放控件 |
| 框选多个节点 | 按住左键拖动空白区域 | 建立逻辑块时进入专用框选模式 |
| 增减选中项 | Ctrl+点击；macOS使用Cmd | 使用全选、专用框选和节点菜单 |
| 打开菜单 | 右键节点、连线或空白处 | 长按对应位置 |

画布缩放范围为30%–200%。节点位于视野外时，点击“适应画布”查看整体布局。点击或拖动小地图可将视野移动至对应位置。

> 快捷键设置页面可保存平移/框选的鼠标按钮设置，但当前画布仍直接使用右键平移、左键框选的判断逻辑。重绑定可能不生效，应以本节默认操作为准。

## 处理链复制

1. 选中需要复用的节点。桌面端可框选，或按住Ctrl逐个增选。
2. 按Ctrl+C，或从节点菜单选择“复制选中”。手机端使用长按菜单。
3. 在空白处右键点击或长按，选择“粘贴”；也可按Ctrl+V。
4. 重新连接选区外的输入和输出。

复制内容为执行复制时的快照，原节点的后续修改不会同步至副本。仅复制**两个端点都在选区内**的连线；跨越选区边界的连线不复制。图内剪贴板不生成可交换配置文件；跨会话复用须使用导出功能或配置库。

## 对齐、等距和自动整理

- 选中至少2个节点后，可通过多选工具条执行左/中/右、上/中/下对齐。
- 水平或垂直等距分布要求至少选中3个节点；2个节点之间不存在可重新分配的中间间距。
- 自动整理用于整体重排节点；适应画布仅调整视野，不改变节点位置。
- 逻辑块可整体拖动和折叠。折叠后的内部节点不参与画布命中检测，并从当前选区移除。

复制节点后，应核对连线并检查副本与原节点的位置，再执行对齐，避免两组节点重叠。

## 快捷键速查

| 动作 | 默认绑定 | 说明 |
| --- | --- | --- |
| 全选 | Ctrl+A | macOS选择逻辑使用Cmd |
| 复制、粘贴节点 | Ctrl+C、Ctrl+V | macOS使用Cmd；文字输入中优先编辑文字 |
| 删除选中 | Delete | 会删除所选节点及相关连线 |
| 撤销 | Ctrl+Z | 可在设置中改绑定；文字输入中优先撤销文字 |
| 重做 | Ctrl+Shift+Z | 可在设置中改绑定 |
| 探测模式、隐藏逻辑线 | 未绑定 | 可配置快捷键，也有工具栏入口 |

全选/复制/粘贴的当前实现仍按A/C/V判断，不保证支持任意重绑定；撤销、重做、探测及隐藏逻辑线使用绑定匹配器。macOS自定义撤销快捷键时，须在设置中明确使用Meta/Cmd并验证；默认Control组合不保证全部自动映射为Cmd。

完整键位、设置入口和其他页面快捷键见[快捷键附录](/reference/shortcuts)。

## 撤销历史的容量与范围

撤销历史保存整个节点图的快照，并按“节点数+连线数”限制容量：总数不超过40时为50步，41–120时为24步，121–300时为12步，超过300时为6步。新的编辑操作会清空重做历史。

图级撤销可用于恢复增删、连线、粘贴和布局等操作；普通参数输入并非都独立建立撤销快照。大量修改前应先[导出配置](saving.md)。
