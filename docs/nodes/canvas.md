# 2.5 画布操作与批量整理

节点多了以后，先把画布摆清楚，通常比继续加节点更有用。你可以移动视野、选择一组节点、复制一段流程，也能让程序自动排一遍。

## 桌面与触屏操作对照

| 操作 | 桌面端 | 移动端 |
| --- | --- | --- |
| 移动节点 | 拖节点主体 | 用手指拖节点主体 |
| 移动画布 | 右键按住拖空白区域 | 在空白处拖动视野 |
| 缩放 | 缩放控件；支持的触控板/滚轮手势 | 双指缩放或缩放控件 |
| 框选多个节点 | 左键拖空白区域 | 建立逻辑块时进入专用框选模式 |
| 增减选中项 | Ctrl+点击；macOS用Cmd | 优先用全选、专用框选和节点菜单 |
| 打开菜单 | 右键节点、连线或空白处 | 长按对应位置 |

画布缩放范围为30%–200%。看不到节点时先点“适应画布”，不要反复放大找。小地图可以点击或拖动，把视野移到对应位置。

> 快捷键设置页面虽然能保存平移/框选鼠标按钮，当前画布仍直接判断右键平移、左键框选。重绑定可能不生效，以本节默认操作为准。

## 复制一段处理链

1. 选中要复用的节点。桌面可框选，也可按住Ctrl逐个加选。
2. 用Ctrl+C，或从节点菜单选择“复制选中”。手机使用长按菜单。
3. 在空白处右键/长按，点“粘贴”；也可用Ctrl+V。
4. 重新接上选区以外的输入和输出。

复制的是当时的快照，原节点后续改变不会带着副本走。只复制**两个端点都在选区内**的连线；跨出选区的线不会带过去。图内剪贴板不等于系统里的可交换配置文件，跨会话复用请用导出或配置库。

## 对齐、等距和自动整理

- 选中至少2个节点后，用多选工具条做左/中/右、上/中/下对齐。
- 至少3个节点才能水平或垂直等距分布；2个节点没有中间间距可调整。
- 自动整理适合整体重排；适应画布只调整视野，不等于重排节点。
- 逻辑块可以整体拖动和折叠。折叠后内部节点不会再参与画布命中，也会从当前选区移除。

建议先复制、确认连线，再对齐。这样不会把复制出来的两组节点叠在一起。

## 快捷键速查

| 动作 | 默认绑定 | 说明 |
| --- | --- | --- |
| 全选 | Ctrl+A | macOS选择逻辑使用Cmd |
| 复制、粘贴节点 | Ctrl+C、Ctrl+V | macOS使用Cmd；文字输入中优先编辑文字 |
| 删除选中 | Delete | 会删除所选节点及相关连线 |
| 撤销 | Ctrl+Z | 可在设置中改绑定；文字输入中优先撤销文字 |
| 重做 | Ctrl+Shift+Z | 可在设置中改绑定 |
| 探测模式、隐藏逻辑线 | 未绑定 | 可配置快捷键，也有工具栏入口 |

全选/复制/粘贴的当前实现仍围绕A/C/V判断，不应保证任意重绑定都可用；撤销、重做、探测及隐藏逻辑线使用绑定匹配器。macOS自定义撤销键请在设置里明确使用Meta/Cmd并实测，不要假定所有默认Control组合都会自动换成Cmd。

完整键位、设置入口和其他页面快捷键见[快捷键附录](/reference/shortcuts)。

## 撤销不是无限历史

撤销保存整张图的快照。按“节点数+连线数”控制历史上限：不超过40为50步，41–120为24步，121–300为12步，更大为6步。新编辑会清空重做历史。

它适合恢复增删、连线、粘贴和布局等操作；普通参数输入并不都独立压栈。大量修改前建议先[导出配置](saving.md)。
