# 2.2 找到节点并放进画布

想加新功能时，先在工具箱选类别，再搜索。这样比在所有节点里翻更容易找到目标。

## 用搜索、排序和收藏找节点

1. 选“视频”“音频”“图片”“通用”或“控制与逻辑”。容器编辑器还会出现“容器”。
2. 在搜索框输入中文名称、英文名称或类型标识，例如“倒放”、Reverse、audioReverse。
3. 结果仍限制在当前类别。找不到时先换类别，别急着认为功能不存在。
4. 按需要切换“名称”或“使用频次”排序。

名称排序用稳定的英文A–Z，**不是中文拼音排序**。使用频次记录成功添加的次数；只看预览不会计数，撤销后重做也不会再算一次。切换类别会清空搜索文字。

| 想做什么 | 桌面端 | 移动端 |
| --- | --- | --- |
| 看节点参数长什么样 | 单击工具项，属性区进入预览 | 点击工具项会直接添加，之后看属性 |
| 添加到画布中心 | 双击工具项 | 点击工具项，工具箱收起并选中新节点 |
| 放在指定位置 | 从工具箱拖到画布 | 长按空白画布，用菜单选择元素 |
| 收藏/取消收藏 | 右键工具项 | 长按工具项 |

收藏项会置顶。“最近使用”按最近添加顺序排列，和累计使用次数不是一回事。元素显示为列表还是芯片受编辑器设置影响，创建方法不变。

## 桌面端：拖入一个节点

以添加“调整音量”为例：

1. 切到“音频”，找到“调整音量”。
2. 从工具箱把它拖到画布空白处，松开。
3. 点击画布里的新节点，确认属性标题是“调整音量”。
4. 调整参数，再把它接进数据链。

单击工具项看到的“预览 · 双击添加到画布”只是临时属性表单，**还没有创建节点**。在预览里填的参数也不要当作新节点的已保存参数；创建后请对实际节点重新确认。

## 手机：点一下添加，再编辑

1. 打开“添加节点”工具箱。
2. 选类别并点目标节点。
3. 工具箱收起，新节点放到当前可视中心。
4. 新节点自动被选中，在属性弹层中继续设置。

> 手机上的工具箱盖在画布上，因此采用点按创建。不要照着桌面教程从工具箱往底下画布拖。

## 在空白处快速添加

桌面右键空白处、手机长按空白处会打开画布菜单。菜单提供常用节点和“全部元素…”，也能全选、粘贴、自动整理、适应画布。在“全部元素…”里选中一项，就会在菜单对应的画布位置添加一次。

## “显示可用”是什么意思

它根据源媒体类型和已知的跨类型能力过滤目录。例如视频能提取音频，音频能生成频谱图或波形图，所以后续音频、图片处理也可能可见。

它没有验证你现在的整张图：看得到的节点仍可能因为接线或参数不对而无法保存。通用节点也仍需选择媒体类型。参阅[连线规则](connections.md)。
