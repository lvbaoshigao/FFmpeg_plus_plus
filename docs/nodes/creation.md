# 2.2 节点查找与创建

添加处理节点前，在工具箱中选择类别，再使用搜索功能定位节点。搜索范围限于当前类别。

## 搜索、排序与收藏

1. 选择“视频”“音频”“图片”“通用”或“控制与逻辑”。容器编辑器还会显示“容器”。
2. 在搜索框输入中文名称、英文名称或类型标识，例如“倒放”、Reverse、audioReverse。
3. 搜索结果限于当前类别。未找到目标时，切换到对应类别后重新搜索。
4. 按需要切换“名称”或“使用频次”排序。

名称排序采用稳定的英文A–Z顺序，**不按中文拼音排序**。使用频次记录成功添加节点的次数；查看预览不计数，撤销后重做不重复计数。切换类别会清空搜索文字。

| 操作目的 | 桌面端 | 移动端 |
| --- | --- | --- |
| 查看节点参数 | 单击工具项，属性区进入预览 | 点击工具项直接添加节点，再查看属性 |
| 添加到画布中心 | 双击工具项 | 点击工具项，工具箱收起并选中新节点 |
| 放在指定位置 | 从工具箱拖到画布 | 长按空白画布，用菜单选择元素 |
| 收藏/取消收藏 | 右键工具项 | 长按工具项 |

收藏项置顶显示。“最近使用”按最近添加顺序排列，不按累计使用次数排序。元素以列表或芯片形式显示，由编辑器设置决定；两种显示形式的创建方法相同。

## 桌面端：拖入一个节点

以添加“调整音量”为例：

1. 切换到“音频”，找到“调整音量”。
2. 将该工具项从工具箱拖至画布空白处后松开。
3. 点击画布中的新节点，确认属性标题为“调整音量”。
4. 设置参数，再将节点接入数据链。

单击工具项显示的“预览 · 双击添加到画布”为临时属性表单，**此时尚未创建节点**。预览表单中的参数不应视为新节点的已保存参数；创建后须核对实际节点的参数。

## 手机端：点按创建与编辑

1. 打开“添加节点”工具箱。
2. 选择类别并点击目标节点。
3. 工具箱收起，新节点放到当前可视中心。
4. 新节点自动被选中，在属性弹层中继续设置。

> 手机端工具箱覆盖画布，采用点按创建方式；从工具箱拖入画布的桌面端操作不适用于此界面。

## 通过画布菜单添加

桌面端右键点击空白处，或手机端长按空白处，可打开画布菜单。菜单提供常用节点和“全部元素…”，以及全选、粘贴、自动整理、适应画布操作。在“全部元素…”中选择一项后，将在菜单对应的画布位置添加该元素。

## “显示可用”的过滤范围

“显示可用”根据源媒体类型和已知的跨类型转换能力过滤目录。例如视频可提取音频，音频可生成频谱图或波形图，因此目录中也可能显示后续音频和图片处理节点。

该过滤功能不校验当前节点图的完整结构；目录中可见的节点仍可能因连线或参数错误而无法保存。通用节点仍须选择媒体类型。参阅[连线规则](connections.md)。
