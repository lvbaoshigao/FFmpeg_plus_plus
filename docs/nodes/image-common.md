# 2.8 图片与通用节点

图片类别提供亮度、噪点、降噪、通道和压缩5种专用操作；转换、缩放、裁剪等操作位于“通用”类别。使用通用节点时，须先选择“媒体类型”，再设置对应参数。

## 通用节点的媒体类型支持范围

| 节点 | 视频 | 图片 | 音频 | 连接后的配置要求 |
| --- | --- | --- | --- | --- |
| 元数据删除 | 支持 | 支持 | 支持 | 确认是否保留章节或删除封面 |
| 格式转换 | 支持 | 支持 | 支持 | 选择格式和编码器；仅修改扩展名不能转换格式 |
| 缩放 | 支持 | 支持 | 不支持 | 视频选择尺寸设置方式，图片选择缩放倍数 |
| 裁剪 | 支持 | 支持 | 不支持 | 打开选区工具，或填写图片裁剪坐标 |
| 旋转翻转 | 支持 | 支持 | 不支持 | 检查默认角度与翻转选项 |
| 色彩调整 | 支持 | 支持 | 不支持 | 视频须勾选所需滤镜，图片直接调整数值 |
| 锐化降噪 | 支持 | 支持 | 不支持 | 视频勾选锐化/降噪，图片调整锐化强度 |
| 叠加 | 支持 | 不支持 | 不支持 | 选择水印/Logo图片 |

通用节点初始未选择媒体类型。连接时可能根据上游节点回填，仍须核对回填结果。切换类型会清除不适用的旧参数。

## 元数据删除

添加节点后须选择媒体类型。视频可勾选“保留章节信息”，默认关闭；音频可勾选“同时删除封面图”，默认关闭；图片直接使用图片元数据删除处理。

章节、标签和内嵌封面属于不同内容。删除音频封面时，须明确勾选相应选项；清除tags不保证删除封面流。

## 格式转换

| 媒体类型 | 初始设置 | 操作要求 |
| --- | --- | --- |
| 视频 | CPU、libx264、AAC等，与音视频处理相同 | 参见[音视频处理](video.md)，并在输出节点确认输出封装 |
| 图片 | PNG、质量95 | 选择PNG/JPG/BMP/WebP/TIFF/ICO；质量设置仅在JPG/WebP格式下显示 |
| 音频 | M4A、AAC | 格式可选M4A/MP3/OGG/FLAC/WAV/AAC，编码器单独选择 |

例如将图片转换为WebP：选择“图片”→输出格式WebP→质量85→连接至输出。音频编码器须与格式兼容；选择MP3格式时，仍须检查编码器。保留AAC编码并将文件名改为.mp3不能完成正确转换。码率和采样率设置见[音质调整](audio.md)。

## 缩放与旋转翻转

视频的“缩放”和“旋转翻转”复用画面变换表单：默认不缩放、不翻转、不旋转；宽高初值1280/720，百分比100%。

- 缩放可选指定宽度、指定高度或百分比；百分比范围1–400%。
- 翻转可选水平、垂直或两者。
- 旋转可选90°、180°、270°。

例如将视频高度缩放至720时，须选择“指定高度”并填写720；仅修改高度值而仍保留“不缩放”模式不会启用缩放。

图片缩放默认为“指定倍数”1倍，范围为0.1–10倍；随机倍数的初始范围为0.5–2。输出尺寸会对齐到偶数像素。图片旋转默认预设角度为90°，也可选择自定义角度或0–360°随机范围。

> 新建图片旋转节点的默认角度为90°，不是“不旋转”。添加后须确认角度；需要指定且可重复的结果时，应使用固定倍数/角度。

## 视频与图片裁剪

### 视频

1. 选择媒体类型“视频”。
2. 选择“保留区域”或“移除区域”，默认保留。
3. 输入参考帧号（初值0）并点“提取”。
4. 打开“选择工具”并绘制选区。
5. 在选择工具中保存，再返回编辑器保存节点图。

默认选区列表为空，未绘制选区时保存会被校验拒绝。选择工具中的撤销仅作用于当前绘制区域，与整个节点图的撤销相互独立。

“移除区域”用于移除选中的边缘/黑边区域，不提供基于内容识别的水印消除功能。

### 图片

点击预览或“打开裁剪工具”进入较大的裁剪窗口，绘制选区后确认；也可手动填写X、Y、宽度和高度。X/Y初值为0，宽高初值为0；源图加载后须根据实际尺寸或选区核对参数，不能将未完成的0尺寸视为有效配置。

上游图片由可视化、帧提取等节点在运行时生成时，编辑阶段可能没有可显示的实际产物。“暂无预览”不表示任务一定失败；可根据已知尺寸手动设置，再运行短任务检查。

## 色彩调整与锐化降噪

视频节点复用滤镜表单。**仅勾选滤镜后才应用对应参数**；默认滤镜列表为空。可勾选亮度、对比度、饱和度、伽马、色相、暗角、视频降噪、视频锐化、黑白。

| 参数 | 初值 | 可调范围 |
| --- | --- | --- |
| 亮度 | 0 | −1–1 |
| 对比度 | 1 | 0–4 |
| 饱和度 | 1 | 0–3 |
| 伽马 | 1 | 0.1–10 |
| 色相 | 0° | −180–180° |
| 暗角 | 约0.6283 | 0–约3.1416 |
| 视频降噪 | 6 | 0–30 |
| 视频锐化 | 1 | 0–5 |

例如需要视频黑白效果时，勾选“黑白”；仅打开表单不会自动添加滤镜效果。

图片“色彩调整”的饱和度、伽马、对比度初值均为1，范围分别为0–3、0.1–10、0–4。“锐化降噪”选择图片类型后使用锐化表单：固定强度初值为1、范围为0–5，随机初始范围为0.5–3。图片降噪须使用下文的专用“图片降噪”节点。

## 叠加（水印/Logo）

本节点仅支持视频。点击“选择图片”可选择PNG/JPG/JPEG/BMP/WebP/GIF等格式；默认位置为右下角，透明度100%、缩放100%、边距16像素。

选择素材后，设置位置、透明度、缩放（1–100%）和边距，并处理短片段以检查实际显示尺寸。素材路径为空时会跳过本节点，**不会因未选择水印而强制报错**；需要水印时须核对素材路径和实际输出。

## 图片类别的5个专用节点

| 节点 | 默认与关键参数 | 操作要求与限制 |
| --- | --- | --- |
| 亮度调节 | 固定值0，范围−1–1；指定范围初值−0.5–0.5 | 例如提高亮度时可先设为0.05；范围模式在指定范围内取值，不同时输出多个亮度版本 |
| 添加噪点 | 均匀分布u、固定强度10；强度0–100，随机范围初值5–50 | 先选择噪点类型，再调整强度；时间变化t主要用于滤镜类型选择，不会将静态图片自动转换为视频 |
| 图片降噪 | NLMeans、固定强度3；范围1–20，随机初值1–10 | 可切换至HQDN3D；先使用低强度并检查细节损失 |
| 通道提取 | 红色R、“保留颜色” | 选择R/G/B，再选择保留该通道颜色或提取为单通道灰度图 |
| 图片压缩 | 保持格式、质量75；可改JPG/WebP/PNG，质量1–100 | 降低JPEG/WebP质量通常可减小文件体积；PNG为无损格式，质量滑块对PNG无效 |

压缩示例：**开始 → 缩放（图片、0.5倍） → 图片压缩（WebP、75） → 输出**。先缩小尺寸再压缩，完成后核对实际输出扩展名和画质。保持原格式且源为PNG时，将质量设为75不保证减小文件体积。
