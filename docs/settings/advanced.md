# 3.12 高级设置：启动、显示、日志与清理

高级设置集中管理性能选项、诊断功能和数据清理。各项功能按需启用；排查问题时，应根据问题类型调整对应选项。

## 显示与返回手势

**预测式返回**只在 Android 生效，用于支持系统返回手势的预览体验；桌面和 iOS 不因此获得同样原生能力。

**高刷新率**位于移动端显示设置。实际原生实现仅 Android：开启会请求当前分辨率下可用的最高刷新率，关闭回到系统偏好；系统限制、功耗策略或查询失败时可能不能达到预期。它改变的是界面刷新偏好，**不是导出视频帧率**。

## 关闭预加载的影响

开启后，启动时只构建/绘制当前页，跳过后台页面构建、字体列表枚举和壁纸解码预热。第一次打开其他页面时现场构建，可能短暂增加 CPU 占用。

它不是“禁止读取字体/图片”，也不会停掉处理任务。自定义字体加载是必要功能，不属于可跳过的预热。

**设置条件：** 若需减少启动时的后台准备，可开启此选项；若优先保证首次切换页面时的响应表现，可保留预加载。比较效果时，应重启应用并按相同顺序访问页面，不应仅依据单次 CPU 瞬时数据判断。

## 调试与日志

| 项目 | 用途 |
| --- | --- |
| 调试模式 | 应用调试相关行为与显示 |
| 非常详细的日志 | 记录底层操作，建议排查时短期开启 |
| 保存日志 | 将日志写到所选位置，需要目录可写 |
| 查看日志 | 打开全局日志页 |

开启非常详细日志时会出现确认提示。问题复现后应关闭此选项，以减少日志量和额外开销。复制与筛选方法见[日志教程](../features/logs.md)。

## 节点使用频次

节点使用频次用于记录操作偏好。“重置”仅清除使用次数，保留收藏、最近使用、项目和其他设置。该操作不可撤销，也不会重置整个软件。

## 清理范围与影响

| 选项 | 清什么 | 代价 |
| --- | --- | --- |
| 清除图片 / 字体 | 导入背景与字体资源 | 需要重新选择/导入；正在使用的已删除导入字体会回退 |
| 清除缓存 | 无引用的导入副本、缩略图、帧预览临时图等 | 预览可能需要重建；仍被项目/队列引用的副本保留 |

清理前，先保存重要配置并确认当前任务状态，再选择清除缓存及所需范围。若要释放导入媒体占用空间，应先移除不再需要的项目或任务记录，然后清理普通缓存。

> **缓存清理会保留仍被引用的临时导入副本。** 因此，清理后可用空间未明显增加时，应检查项目和队列是否仍引用这些副本。缓存清理不会删除原媒体或成品，也不会清空所有设置。
