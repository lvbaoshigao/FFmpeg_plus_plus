# 3.12 高级设置：启动、显示、日志与清理

高级页把性能选择、诊断和数据清理放在一起。日常不需要全开；遇到一个具体问题，找对应项目更有效。

## 显示与返回手势

**预测式返回**只在 Android 生效，用于支持系统返回手势的预览体验；桌面和 iOS 不因此获得同样原生能力。

**高刷新率**位于移动端显示设置。实际原生实现仅 Android：开启会请求当前分辨率下可用的最高刷新率，关闭回到系统偏好；系统限制、功耗策略或查询失败时可能不能达到预期。它改变的是界面刷新偏好，**不是导出视频帧率**。

## “关闭预加载”到底关什么

开启后，启动时只构建/绘制当前页，跳过后台页面构建、字体列表枚举和壁纸解码预热。第一次打开其他页面时现场构建，可能短暂增加 CPU 占用。

它不是“禁止读取字体/图片”，也不会停掉处理任务。自定义字体加载是必要功能，不属于可跳过的预热。

**怎么选：** 启动时想少做后台准备，可以开启；更看重第一次切页顺畅，可以保留预加载。比较时重启一次并用相同页面顺序体验，别只看某一瞬间的 CPU。

## 调试与日志

| 项目 | 用途 |
| --- | --- |
| 调试模式 | 应用调试相关行为与显示 |
| 非常详细的日志 | 记录底层操作，建议排查时短期开启 |
| 保存日志 | 将日志写到所选位置，需要目录可写 |
| 查看日志 | 打开全局日志页 |

非常详细日志会先确认。复现后关掉，可减少日志量和额外开销。复制与筛选方法见[日志教程](../features/logs.md)。

## 节点使用频次

节点使用频次用于记录操作偏好。“重置”只清使用次数，保留收藏、最近使用、项目和其他设置；重置不能撤销。不要把它当作重置整个软件。

## 清理前先认清两种范围

| 选项 | 清什么 | 代价 |
| --- | --- | --- |
| 清除图片 / 字体 | 导入背景与字体资源 | 需要重新选择/导入；正在使用的已删除导入字体会回退 |
| 清除缓存 | 无引用的导入副本、缩略图、帧预览临时图等 | 预览可能需要重建；仍被项目/队列引用的副本保留 |

操作顺序：先保存重要配置，确认当前任务情况，点清除缓存，再选择真正需要的范围。想释放导入媒体占用时，先处理不再需要的项目/任务记录，再清普通缓存。

> **清完空间没明显减少，先看引用。** 为了不破坏当前项目和队列，仍引用的临时导入副本不会强删。清理缓存也不是删除原媒体、成品或清空所有设置的入口。
