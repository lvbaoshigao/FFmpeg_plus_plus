# 3.9 通用与外观设置

本页用于配置界面语言、主题、字体、背景和材质动效。调整时可按文字可读性、主题与背景、材质与动效的顺序进行，便于识别各项设置对界面的影响。

## 查找设置入口

桌面版设置页通过左侧分区导航和右侧选项访问；移动端先显示设置分组，选择分组后再编辑具体选项。搜索框可跨分区搜索，选择结果会定位到对应设置卡片。移动端部分选项位于第三级页面，不会全部显示在首屏。

“通用”目前主要用于设置界面语言，可选择中文或 English。此设置仅改变应用界面语言，不会翻译 FFmpeg 诊断信息、文件名或外部模型的回答。

## 推荐调整顺序

1. **模式**：选择深色或浅色模式。
2. **字体**：调整字号和字重，并检查项目列表与参数面板的可读性。
3. **主题色**：启用全局主题色，并选择预设、自定义颜色或渐变。关闭此选项后，界面恢复应用默认强调色；已选颜色会保留，并在重新启用后继续使用。
4. **背景**：导入图片并设置不透明度，避免降低参数文字的可读性。
5. **材质与动效**：选择样式预设，再分别调整卡片、弹窗、下拉菜单、模糊和边框。

## 主题色、动态取色与材质的作用范围

| 设置 | 作用范围 | 限制与说明 |
| --- | --- | --- |
| 全局主题色 | 全局强调色 | 关闭后不会清除已选颜色 |
| 动态取色（移动端） | 使用系统提供的配色来源 | 开启时，手动预设和自定义取色入口会禁用；实际取色能力受平台影响 |
| 主题色协调度 | 使用主题色的卡片、底栏和药丸底色 | 不表示全局透明度，也不会改变输出视频 |
| 移动端主题 | 移动界面的表面和圆角等视觉样式 | 与主题色、字体和材质分别设置 |
| 样式预设 | 一组界面材质参数 | 不会同时替换背景图片、取色来源或独立的移动端主题 |

## 字体与背景

桌面版可通过字体选择器选择系统字体或导入 TTF/OTF 文件。移动端提供系统字体和导入字体，不显示完整系统字体列表。字体页提供预览；选择字重后，应检查中文、英文和数字的显示效果。

应用内字号范围为 10–21。部分固定宽度选项不随应用字号变化，系统文字缩放仍可能生效。因此，部分文字的缩放比例可能与字号滑块不同。

背景选择支持 JPG/JPEG、PNG、BMP 和 WebP。导入及解码过程对大图设有资源预算，因此选择失败不一定由文件损坏导致。排查时，可先选择一张常见尺寸的静态图片，再查看日志。清理“图片/字体”会删除已导入资源，之后需重新选择，详见[高级设置](advanced.md)。

## 玻璃、卡片和菜单分别设置

“界面材质与动效”包括样式预设、卡片与弹窗、玻璃与边框以及动效设置。

- **卡片样式**控制遵循全局卡片设置的界面内容。
- **设置卡片样式**可继承全局设置，也可单独设为毛玻璃或主题色实心。
- **弹窗与面板**可单独选择液态玻璃、模糊或主题风格。
- **下拉菜单**可独立选择不透明主题、液态玻璃、主题色毛玻璃、高光玻璃或极简灰。
- 模糊强度、玻璃主题色、边框、通透度、高光和边缘光用于微调界面材质。

> **材质设置分别作用于卡片、设置卡片、弹窗和下拉菜单。** 背景影响文字对比度时，可选择不透明风格；动效影响界面体验时，可关闭相关动效。调整这些选项不需要重置其他设置。

## 导航和编辑器外观

桌面版可调整侧栏和顶栏样式。移动端可设置导航位置（自动、底部、左侧或右侧）、药丸样式、滑动时自动收起底栏，以及底部操作的左右位置。自动模式根据屏幕宽高比选择位置；横屏或宽屏设备可能使用侧边导航。

“选中遮罩”适用于主导航、设置导航和分段选项，与卡片材质分别设置。节点编辑器外观包括元素布局、画布背景、逻辑门符号标准、小地图和网格吸附；详见[编辑器设置](editor.md)。
