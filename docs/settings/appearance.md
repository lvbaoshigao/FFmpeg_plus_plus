# 3.9 通用与外观：先看清，再慢慢调

不需要一次把所有样式都配完。先让文字可读，再选主题与背景，最后调玻璃和动效，比较容易知道是哪一个选项改变了画面。

## 先找到设置

桌面设置用左侧分区导航和右侧选项；移动端先显示分组行，点进去再改具体内容。搜索框可以跨分区搜索，点结果会定位到对应设置卡片。移动端有些内容还放在第三级页面，不是所有开关都在第一屏。

“通用”目前主要是界面语言，可以选择中文或 English。它改变的是应用界面，不会翻译 FFmpeg 诊断、文件名或外部模型的回答。

## 推荐调整顺序

1. **模式**：选适合环境的深色或浅色。
2. **字体**：先调字号、字重，确认项目列表和参数面板都能看清。
3. **主题色**：启用全局主题色，再选择预设、自定义颜色或渐变。关闭后恢复应用默认强调色，已选颜色会保留，重新开启后恢复使用。
4. **背景**：导入图片，调不透明度，避免干扰参数文字。
5. **材质与动效**：先试样式预设，再按需要微调卡片、弹窗、下拉菜单、模糊与边框。

## 主题色、动态取色、材质不是同一个东西

| 设置 | 影响什么 | 容易误解的地方 |
| --- | --- | --- |
| 全局主题色 | 全站强调色 | 关掉不会抹掉之前选的颜色 |
| 动态取色（移动端） | 使用系统提供的配色来源 | 开启时手工预设/自定义取色入口会置灰；实际可取色能力受平台影响 |
| 主题色协调度 | 跟随主题色的卡片、底栏、药丸底色 | 不是全站透明度，也不改变输出视频 |
| 移动端主题 | 移动界面的表面、圆角等视觉约定 | 与主题色、字体、材质仍是独立设置 |
| 样式预设 | 一组界面材质参数 | 不会一并替换背景图片、取色来源或独立移动主题 |

## 字体与背景

桌面可从字体选择器选系统字体，也能导入 TTF/OTF。移动端只提供系统字体与导入字体，不展示整份系统字体列表。字体页有预览，选好字重后看中文、英文、数字是否都正常。

应用内字号范围为 10–21，部分固定宽度选项有意不跟随应用字号，系统文字缩放仍可能生效。所以不是每一段文字都会与滑块完全同比例放大。

背景选择支持 JPG/JPEG、PNG、BMP、WebP。大图会受导入和解码预算保护，选择失败不一定是文件损坏。先试一张常见尺寸的静态图片，再查日志。清理“图片/字体”会删除导入资源并需要重新选择，见[高级设置](advanced.md)。

## 玻璃、卡片和菜单分别设置

“界面材质与动效”分成样式预设、卡片与弹窗、玻璃与边框、动效几个关注点。

- **卡片样式**控制遵循全局卡片设置的内容。
- **设置卡片样式**可以跟随全局，也能覆盖成毛玻璃或主题色实心。
- **弹窗与面板**有自己的液态玻璃、模糊或主题风格。
- **下拉菜单**还可独立选不透明主题、液态玻璃、主题色毛玻璃、高光玻璃、极简灰。
- 模糊强度、玻璃主题色、边框、通透度、高光和边缘光用于进一步微调。

> **改了一个样式，别期待所有东西都一起变。** 先看它写的是卡片、设置卡片、弹窗还是下拉菜单。遇到背景太花、对比度不够，先切不透明风格；觉得动画太重，再关闭相关动效，不必重置全部设置。

## 导航和编辑器外观

桌面可调侧栏与顶栏样式。移动端还可选导航自动/底部/左侧/右侧、药丸样式、滑动时自动收起底栏及底部动作的左右位置。自动位置按屏幕横纵比决定，横屏/宽屏可能变成侧边导航。

“选中遮罩”用于主导航、设置导航与分段选项，和卡片材质分开。节点编辑器外观包含元素布局、画布底色、逻辑门符号标准、小地图与网格吸附；具体见[编辑器设置](editor.md)。
