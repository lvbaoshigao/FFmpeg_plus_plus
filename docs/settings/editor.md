# 3.10 编辑器设置

编辑器设置分为两类：一类决定在文件中选择“编辑”后打开的编辑模式，另一类控制节点画布的显示方式与保存行为。“传统布局”仍可使用；传统编辑模式已移除，两者并非同一功能。

## 编辑模式设置入口

| 平台 | 入口 |
| --- | --- |
| 桌面 | 设置 → 编辑器 → 编辑模式 / 自动保存 / 快捷键 |
| 移动端 | 设置 → 外观 → 节点编辑器 → 编辑模式 / 自动保存 |

当前提供两种编辑模式：

- **节点编辑器**：图形节点画布，适用于分支、逻辑结构和复杂多步流程。
- **快速模式**：打开[快捷配置向导](../features/quick-config.md)，用于单文件顺序处理。

切换模式主要改变编辑入口，不会自动将复杂节点图转换为顺序链。快速模式遇到分支、逻辑结构或不支持串行编辑的节点时，会提示切换到节点编辑器。

## 开启草稿自动保存

1. 打开“自动保存”。
2. 开启“启用节点编辑器自动保存”。
3. 选择保存间隔：10 秒、30 秒、1 分钟、2 分钟或 5 分钟。
4. 对重要更改仍应执行主动保存；需要交换配置或长期保管时，将配置保存到库或导出。

自动保存用于在应用异常退出后恢复草稿，不会完整备份所有媒体、任务和外部资源，也不支持编码任务断点续传。画布恢复的具体交互见[保存与恢复](/nodes/saving)。

移动端“节点编辑器横屏”选项也位于此页面。开启后，节点编辑器默认以横屏打开，为画布提供更宽的显示区域。此选项仅影响节点编辑器，不会锁定其他主页面的屏幕方向。

## 画布显示与操作

外观 → 节点编辑器包含：

| 项目 | 如何使用 |
| --- | --- |
| 元素布局：传统/列表 | 选择编辑器元素的排布方式，不改变图执行语义 |
| 画布背景 | 选择跟随全局、灰、黑或白，以满足可读性要求 |
| 逻辑门标准 | 选择 ANSI/IEEE 或 IEC；此选项仅改变逻辑门符号表示方式 |
| 画布小地图 | 在右下角查看整体画布与当前视口；选择区域可跳转 |
| 拖动对齐网格 | 拖动节点时吸附到网格，便于对齐 |
| 移动端界面尺寸 | 设置顶部菜单栏与缩放药丸大小，范围为 50%–160% |

> **画布设置仅影响编辑器界面。** 更改布局、逻辑符号或界面尺寸后，可返回画布检查显示效果；这些选项不是视频参数，不会写入输出画面。

## 桌面元素与属性窗口

元素栏和属性栏均提供独立窗口入口。将其中一栏移出主窗口后，另一栏会使用右侧全部可用高度；将两栏都移出后，画布会占用右侧区域。独立窗口关闭或重新吸附时，对应栏目会恢复。

元素分类用于切换视频、音频、图片、通用以及控制与逻辑节点。搜索和排序仅作用于当前分类。

## 快捷键

桌面版可在“快捷键”中配置组合键并检查冲突，也可调整画布平移和框选使用的鼠标按键。部分操作默认未绑定，使用前必须先配置。完整默认表和作用范围见[快捷键附录](../reference/shortcuts.md)。
