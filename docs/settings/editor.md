# 3.10 编辑器设置：选入口，留草稿，调画布

这里有两类设置：一类决定点文件“编辑”后打开什么，另一类决定节点画布怎样显示与保存。把它们分开理解，就不会把“传统布局”误认成已经移除的传统编辑模式。

## 编辑模式放在哪里

| 平台 | 入口 |
| --- | --- |
| 桌面 | 设置 → 编辑器 → 编辑模式 / 自动保存 / 快捷键 |
| 移动端 | 设置 → 外观 → 节点编辑器 → 编辑模式 / 自动保存 |

当前可选编辑模式只有两个：

- **节点编辑器**：蓝图式画布，适合分支、逻辑与复杂多步流程。
- **快速模式**：打开[快捷配置向导](../features/quick-config.md)，适合单文件串行处理。

切换模式主要改变编辑入口，不会让一个复杂图自动变成简单链。快速模式遇到分支、逻辑或不支持串行编辑的节点，会提示转节点编辑器。

## 开启草稿自动保存

1. 打开“自动保存”。
2. 开启“启用节点编辑器自动保存”。
3. 选保存间隔：10 秒、30 秒、1 分钟、2 分钟或 5 分钟。
4. 重要更改仍主动保存；需要交换或长期保管时，再保存到库/导出配置。

自动保存为异常退出提供草稿恢复机会，不是对所有媒体、任务、外部资源的完整备份，也不是编码任务断点续传。画布恢复的具体交互见[保存与恢复](/nodes/saving)。

移动端“节点编辑器横屏”也位于这个页面。开启后进入节点编辑器默认横屏，给画布更宽的空间；不要把它理解成所有主页面都锁横屏。

## 让画布更好操作

外观 → 节点编辑器包含：

| 项目 | 如何使用 |
| --- | --- |
| 元素布局：传统/列表 | 选择编辑器元素的排布方式，不改变图执行语义 |
| 画布背景 | 跟随全局、灰、黑或白，按可读性选择 |
| 逻辑门标准 | ANSI/IEEE 或 IEC，改变符号表达 |
| 画布小地图 | 在右下角看整体与视口，点击跳转 |
| 拖动对齐网格 | 拖节点时吸附，方便排整齐 |
| 移动端界面尺寸 | 调顶部菜单栏与缩放药丸大小，范围 50%–160% |

> **先改一个，再试一次。** 比如先开启小地图，回画布确认能看全流程，再调整吸附。布局、逻辑符号、界面大小都不是视频画面参数，不会写进输出画面。

## 桌面元素与属性窗口

元素栏和属性栏各自提供独立窗口入口。把其中一栏移出主窗口后，另一栏会使用右侧全部可用高度；两栏都移出后，画布收回右侧区域。独立窗口关闭或吸附回来时，对应栏目会恢复。

元素分类用于切换视频、音频、图片、通用及控制与逻辑节点，搜索和排序继续作用于当前分类。

## 快捷键

桌面可以到“快捷键”录入组合键、检查冲突，也可调整画布平移/框选鼠标按钮。某些动作默认未配置，必须先绑定。完整默认表与作用范围见[快捷键附录](../reference/shortcuts.md)。
