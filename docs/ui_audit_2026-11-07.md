## P1 · 违反项目自己的内存红线（实时 blur）— 已修复

项目在 `widgets/liquid_glass_fallback.dart:115-152` 定义了 `cachedGlassBlur()`，注释明确写着
「`ui.ImageFilter.blur(...)` 每次调用都会新建一个持有 native handle 的 Dart 对象并注册 finalizer；
在 build 里现场构造 → 滚动时每帧 × 每张可见玻璃卡各新建一个」。

全库 12 处 `BackdropFilter`，**10 处已走缓存，2 处漏了**：

| 位置 | 原代码 | 修复 |
|---|---|---|
| `widgets/option_menu_bar.dart:119` | `ui.ImageFilter.blur(sigmaX: blur, sigmaY: blur)` | → `cachedGlassBlur(blur)` |
| `widgets/model_editor_sheet.dart:233` | `ui.ImageFilter.blur(sigmaX: 18, sigmaY: 18)` | → `cachedGlassBlur(18)` |

两处都补了 `import 'liquid_glass_fallback.dart';`，并删掉因此不再使用的 `import 'dart:ui' as ui;`。
`option_menu_bar` 的 σ 只有 0 / 8 / 12 三档，`model_editor_sheet` 的 σ 是常量 —— 都是缓存的最佳场景。

## P2 · 控件尺寸体系未落地

`theme/app_control_size.dart` 已经定义得很完整（28/32/36/44 四档 + 统一 radius 8/10/12），
但实际执行情况：

1. **只有 7 / 127 个文件引用了 `AppControlSize`**，其余仍是手写数值。

2. **`widgets/step_editors/editor_kit.dart:277` 的 `editorDenseField` 缺 `visualDensity`** —— 已修复。
   它原先自定义 `border: circular(8)` + `contentPadding: h12/v10`，但没传 `AppControlSize.fieldDensity`。
   `app_theme.dart:126` 的文档明确写：桌面端 `ThemeData.visualDensity` 默认是 `compact(-2,-2)`，
   `InputDecorator` 会额外减 8px。⇒ **桌面端 step editor 属性面板的输入框，比设置页同档输入框矮 8px**。
   现改为 `borderRadius: 10`（对齐主题）+ `visualDensity: AppControlSize.fieldDensity`。
   这一处影响 `step_editors/` 下约 30 个编辑器。

3. **圆角取值 21 种**（未改）：`8`(104) / `10`(54) / `6`(42) / `12`(32) / `14`(23) / `16`(17) /
   `4`(12) / `999`(7) / `9`(6) / `20`(6) / `2`(6) / `11`(3) / `5`(3) / `19`(3) / `3`(2) /
   `22`(2) / `18` / `13` / `7` / `1` / `100`。

4. **固定高度 `SizedBox(height:)` 20 种取值**（未改）：`8`(206) / `6`(63) / `4`(54) / `12`(51) /
   `10`(48) / `2`(45) / `16`(16) / `14`(14) / `3`(13) / `20`(5) / `24`(4) / `30`(4) / `240`(4) …

5. **动画时长 25 种**（未改）：150ms(8) / 160ms(6) / 180ms(14) / 200ms(17) / 220ms(13) / 240ms(6) /
   260ms(6) / 300ms(11) …

**为什么 3/4/5 没动**：这些不是「错误值」。`999` 是胶囊、`100` 是 toast、`22` 是药丸、

「嵌套容器内圈比外圈小 1~3px」的刻意做法。批量替换成四档会破坏这些有意为之的形态，
属于设计系统重构而非 bug 修复，需要先定规范（目标档位 + 哪些保留例外）再逐处替换。

## P3 · 布局与文本健壮性 — 已修复

1. **`pages/pipeline_editor_page.dart:17197 / 17222`** — AI 历史菜单的两个 `ListTile` 标题
   （「保存当前会话」「清空历史」）`maxLines: 1` 但没设 `overflow`，默认 `clip` 会硬切。
   已补 `overflow: TextOverflow.ellipsis`。

   **`pages/config_library_page.dart:192`** — `SegmentedButton` 的「新版 Beta」段标签，
   `maxLines: 1 + softWrap: false` 同样缺 `overflow`，已补。

   ⚠️ 更正：初版报告写的「同类 8 处」经逐处核实后只有上述 3 处成立。其余 5 处
   （`ai_settings_mobile.dart:1725`、`container_detail_page.dart:260`、
   `pipeline_editor_page.dart:8036/17080`、`task_card.dart:2166`）外层都已有
   `FittedBox.scaleDown`（会等比缩放而不是裁切），或本身是 1~2 字符的序号 ——
   在这些位置补 `overflow` 会被宽松/无界约束吞掉，是无效修改，故未动。

2. **`widgets/step_editors/frame_step_editor.dart:249 / 273`** — 两处「提取帧率」行都是
   「标签 + 固定 80 宽输入框 + 间距 12 + 带插值的动态文本」，**动态文本没有 `Flexible`**：

   ```dart
   Row(children: [
     Text('提取帧率: '),
     SizedBox(width: 80, child: TextFormField(...)),
     const SizedBox(width: 12),
     Text('≈ $frameCount 帧'),   // ← 原：无 Flexible / 无 overflow
   ])
   ```

   移动端属性面板扣掉内边距后宽度约 300~330，帧数达到 7 位、或用户放大字号时会溢出。
   两处均已改为 `Flexible(child: Text(..., maxLines: 1, overflow: ellipsis))`。

3. **`widgets/install_dialog.dart:302`** — 文件卡标题行：
   `Icon + Text(name) + Spacer + Text('已选择')`，`name` 是下载包名，裸 `Text` 会让整行溢出。
   已改为 `Expanded(Text(name, maxLines:1, overflow: ellipsis))` 并去掉 `Spacer`
   （`Flexible` + `Spacer` 会让文字只拿到一半剩余宽度，效果反而更差）。

4. **`widgets/install_dialog.dart:327`** — 两个按钮并排（「打开下载页 / 选择已下载的文件」）
   都没有 `Flexible`。已各自包 `Flexible` 并给 label 加 `maxLines + ellipsis`；
   `Flexible` 是 loose，宽度够时按钮仍按内容宽度排布，只在窄屏/大字号时收缩。
